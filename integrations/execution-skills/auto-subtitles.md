# Auto-subtitles — ABBY后期字幕

基于sketch-man/claude-skill-auto-subtitles，MIT许可；保留安装目录LICENSE与 `references/SKILL.source.md`。原文可供实现参考，其顶部色块、英文分块、大模型与固定尺寸均非默认。本适配入口由ABBY维护。

## 路由和准备

ABBY任务先沿用其 `references/generated-clean-final-captioned.md` 和 `references/installed-execution-skills.md`。剪辑锁定后再处理字幕。用户仅要剧本、提示词或无对白视频时不运行字幕流程。

复用已知文件、语言、画幅与偏好，不照抄上游七项问卷。读取本地运行配置并确认转写程序、FFmpeg subtitles/ass滤镜和中文字体。缺少会影响结果的信息才简短询问。安装依赖不代表转写模型已加载或真实音频已通过验收。

## 执行

1. 核对最终母版的时长、画幅及实际音轨，源文件只读；为新导出使用未占用路径。
2. 通过FFmpeg提取16kHz单声道音频供识别，保留母版原声音轨供最后导出。Apple Silicon使用已安装mlx-whisper；复用已缓存模型。新模型首次运行时记录来源、大小与验证状态，不每次重新安装，不默认下载large-v3。
3. 在独立Python环境调用 `mlx_whisper.transcribe(audio_path, path_or_hf_repo=model_path_or_repo, word_timestamps=True)`，以当前安装版签名为准。让工具识别实际语言；中文为主但含英语时逐句复核，不用翻译模式替换英文台词。保存原始识别JSON。
4. 对照实际发声校对人名、英语惯用语、数字及笑点；剧本用于比对，不把未说出的台词补进字幕。静音段疑似识别结果需试听，不按固定词表误删真实对白。
5. 生成SRT与ASS，时间轴基于最终母版。中文按完整语义分句，一般每行12—18字、最多两行，长句再按画面与语速调整；英语按词组断行。不能让翻译或笑点解释提前出现；字幕随发声出现，结束消失。
6. 默认下方安全区白字细深色描边，使用实际可用中文字体，字号和边距按母版尺寸缩放。避开脸、手、道具，画幅不改变；不上顶部大色块、不套固定1080×1920尺寸。ASS文本需转义花括号、反斜线和换行，避免识别文本变成样式命令。
7. 用FFmpeg subtitles/ass滤镜烧录到新文件；实际输入/输出路径用参数数组传入，包含标点的字幕路径通过临时安全文件名处理。保留原人声及环境声，不添加BGM，不把整条音轨静音。兼容的音轨可以复制，不兼容时明确转码。
8. 检查导出时长、音轨、中文缺字、同步、两行可读性与首尾切点，抽看字幕密集处并试听关键对白。保存干净母版、JSON、校对SRT/ASS和有字幕成片，不按上游示例自动删ASS。

## 完成条件

字幕渲染小样只证明字体与烧录；模型导入只证明依赖可加载；必须实际转写并校对后才能说本片字幕完成。依赖、模型或账号有阻碍时说明具体阶段，继续完成不受影响的工作，不把流程文档当已生成视频。
