# 《冰冰和小乌龟》工作目录接入规则

本目录的视频制作以GitHub项目[ABBY.REN-SEEDANCE](https://github.com/abbyren415215-bit/ABBY.REN-SEEDANCE)为准。唯一执行入口为已安装的`abby-seedance/SKILL.md`；用当前技能目录解析路径，不依赖旧聊天记忆。

在允许读取时，读取ABBY入口与`projects/bingbing/current-state.md`、`workflow.md`、`series-bible.md`、`production-protocol.md`，再按任务读取摄影或修复模块。JACOB是原始摄影基础，其他来源已在ABBY内吸收，不并行启动多套视频工作流；视频不混用人像摄影技能。

优先级：用户最新明确决定 → 当前已确认项目状态 → ABBY项目规则 → JACOB原文。已确认剧情、台词、人物、衣服、发型、183/168厘米身高、15厘米差、16:9画幅和分段不得擅改。

每个独立镜头必须写时间、焦段mm、景别、机位、运镜、光源、动作、声音归属和可见结束状态。前中后都有有效场景镜头；30秒片全部台词25秒前结束，最后5秒无台词，最后1.5秒闭口且构图与焦点稳定。无字幕/手机文字/BGM/第三人清晰对白；素材逐份@绑定且只列现有使用项。

永久声音与字幕门禁：按稳定生成协议0.5执行。所有视频禁止自动字幕；画内对白仅生成人声与口型，消息画外音和内心独白仅人声、人物闭口，每句注明不生成字幕。全片禁止BGM、配乐、歌曲、哼唱、音乐性转场及环境音乐，只留已确认剧情角色人声、合理环境声和动作同步声。禁止的是未授权背景第三人清晰对白，不误禁妈妈等已确认配角。逐镜列具体声源，不加无来源音效；全局与末尾重复锁定。明确要求的微信界面/剧情道具文字只在该任务按指定内容允许，不视作对白字幕。此细则优先于上文“无手机文字”的笼统表述。

固定场景/家具门禁：已有教室图与桌椅图时，两项必须同时进入素材清单并逐份@绑定，不能只挂人物后用文字重建空间。用户接受的成片偏差优先用于该段续拍，不重跑可用视频；旧素材保留，新旧版本不混绑。第七集成片采用暖棕亮面双拼单人桌，参考版本见current-state及episode-07-continuity；未见细节的生成补全不得当成实测事实。

用户要“剧本”时给完整走势；要“提示词”时仅给当前一段（通常30秒，补拍按指定10/15秒），不一次输出全剧各段。用户只要提示词时直接在聊天给一个最终版本，不读文件/图片、不运行命令、不新建文件；用会话已有规则，不谎称读过最新仓库。图片生成/修改先取得同意；不自动提交即梦生成。

用户已授权每项工作流更新同步GitHub。维护、修复或明确确认永久规则时，依`references/maintenance.md`更新权威文件和CHANGELOG，精确暂存、提交、推送并核验远端。普通问题或未确认提示词草稿不自动发布；本轮禁止工具时记录待同步，不能声称完成上传。

本地固定设定档及稳定协议中的通用规则与仓库对应文本一起维护；本地独有剧情不得为了镜像一致上传。公开仓库不默认上传图片、音色、成片、凭据或个人绝对路径。发生冲突保留用户改动和远端历史，不强推。

近期连续性与表演门禁：依稳定协议0.7—0.10先核对段号、续写/替换/补拍范围、已用台词、角色已知信息和上段结束状态。取消逐句先吸气/叹气的表演模板；对白优先清晰近景，中远景保留动作与空间职责，不以焦段或高清词承诺生成质量。消息画外音与内心独白时可见人物闭口；电话声音不改成窗口喊话。素材按用户实际可用项列清单，不将未保存的图或不存在的音色列为必传。具体剧本、分段进度和当集素材记录只存工作目录本地剧本资料，不同步GitHub；用户已接受的剧情不重写，助手草稿不当定稿。
