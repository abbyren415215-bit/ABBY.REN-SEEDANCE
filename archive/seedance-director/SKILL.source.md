# Seedance Director

把用户的意图编译成一份短片拍摄指令。先保证动作可读、参考素材分工明确和时长可执行，再增加风格语言。不要把“更长”误当成“更专业”。

## 核心原则

1. 先理解观众最终应看到和感受到什么，再选择镜头、光线、表演和声音。
2. 优先执行用户已经说清的决定；不要重新询问时长、画幅、人物或风格。
3. 信息足够时直接生成。只有缺失项会实质改变主体、叙事结局、素材顺序或交付画幅时，才一次性追问，最多三个问题；每题给出默认值。
4. 默认一次生成只承载一个清楚的主概念。普通镜头只保留一个主动作和一个主运镜；商业卡点蒙太奇可以包含多个短镜头，但每个短镜头仍只承载一个可瞬间读懂的画面事件。
5. 为每个参考素材指定一个主要任务，并明确哪些内容不得从该素材迁移。
6. 未实际查看或听取附件时，明确说明只能依据用户描述；绝不声称已经看过、听过或验证过。
7. 把模型、时长、比例、分辨率和声音开关放在“建议设置”中，不用 `4K/8K/神作` 等空泛词代替平台设置。
8. 对人物肖像、品牌、音乐和受保护角色保留权利与授权边界，不提供绕过平台限制的话术。
9. 把“更细节”理解为状态、尺寸、接触、因果、反应延迟和镜头交接更明确，而不是形容词、镜头数或提示词长度更多。
10. 除非用户明确要求静音、只保留原声或提供了其他音乐方案，默认同时设计与题材和产品气质匹配的原创感纯音乐、选择性动作拟音与空间环境声；声音必须跟随可见动作，不凭空出现。

## 工作流

### 1. 路由任务

先判断主模式：

- `text`：纯文字创造新视频。
- `first-frame`：从一张严格首帧开始运动。
- `first-last`：在严格首帧与尾帧之间完成变化。
- `multimodal`：用图片锁人物/产品/环境，用视频借动作/运镜/节奏，用音频借音色/音乐/环境声。
- `edit`：修改已有视频中的指定元素，保留其他内容。
- `extend`：从已接受视频的真实开头或结尾继续。
- `sequence`：完整故事超过单次生成容量，拆成连续片段。
- `diagnose`：根据失败成片或已有提示词定位最小问题并修复。

未知模型版本时先问清 `Seedance 2.0` 还是其他版本，或只输出通用创作语言而不声称 2.0 的硬限制适用。涉及平台限制或引用语法时读取 [platform-profile.md](references/platform-profile.md)。

### 2. 建立内部创作简报

从用户原话提取或合理默认：目标观众、发布场景、主体、开场状态、触发事件、主动作、可见终点、场景、情绪、视觉体系、主运镜、声音、时长、画幅和必须保持不变的内容。

对叙事/表演内容，在内部补齐：

- 这一段在故事中的作用；
- 开始与结尾发生的可见变化；
- 人物真正想做什么；
- 一个细小但能被拍到的克制动作；
- 一个不可替代的具体细节；
- 一个拒绝采用的套路化处理。

对产品、环境、VFX 等非叙事内容，不强行编造人物心理，只写清展示目的和视觉终点。具体方法读取 [creative-direction.md](references/creative-direction.md)。广告、预告、MV、时尚片或用户明确要求快切/卡点时，还要读取 [commercial-montage.md](references/commercial-montage.md)。人物需要吃、喝、咬、涂抹、佩戴、拥抱、握持或接触脸部时，必须读取 [performance-continuity.md](references/performance-continuity.md)。

任何带声音的视频都要建立声音分镜。广告、产品片、UGC、社交短片或用户要求“生成后直接发布/无需剪辑”时，必须读取 [sound-design.md](references/sound-design.md)：先确定纯音乐的品牌气质、速度与乐器，再只为画面中真实发生的动作配置拟音，最后规定环境声、音乐闪避和结尾收束。用户口语中的“咬东西、开门、放钥匙的配音”按动作拟音/SFX理解，不擅自增加旁白。

### 3. 规划参考素材

按用户实际上传顺序编号。默认即梦中文界面使用 `@图片1`、`@视频1`、`@音频1`；如果界面已经生成了不同的引用标签，逐字保留。

为每个素材记录：

`编号 → 可读别名 → 主要任务 → 要迁移的维度 → 禁止迁移的维度`

例如：`@视频1（运镜参考）只提供横向跟拍路径和剪辑节奏；不要迁移其中的人物、服装、场景色调和原声。`

两个及以上素材时，不使用“参考全部素材”这类模糊说法。模式与写法读取 [prompt-patterns.md](references/prompt-patterns.md)。

### 4. 控制密度

先选密度路线，不再用一套镜头上限覆盖所有类型：

| 时长 | 连续表演/叙事 | 标准广告 | 商业卡点蒙太奇 |
|---|---:|---:|---:|
| 4–6 秒 | 1 | 1–2 | 2–3 |
| 7–9 秒 | 1–2 | 2–3 | 3–5 |
| 10–12 秒 | 2–3 | 3–4 | 4–6 |
| 13–15 秒 | 3–4 | 4–5 | 6–9 |

商业卡点蒙太奇只在主体、产品、地点和光线逻辑稳定，且多数镜头是单一姿态、微距插入或材质变化时使用；每增加一个新人物、新地点或复杂接触动作，按两个短镜头的负担计算。吃喝、嘴部接触、脸部涂抹等高风险表演优先走 4–5 镜头/15 秒，并给核心表演一个连续 3–5 秒镜头；不要为了“像广告”硬扩成 8 镜头。15 秒最后为产品/结论保留约 2–3 秒。

默认使用“镜头1 / 镜头2 / 镜头3”的事件顺序。卡点任务使用融合标记：`镜头N（约X–Y秒，硬切/动作切/匹配切）`，时间窗只表达目标节奏，不承诺逐帧精确。高密度单次生成必须写明独立切镜、镜头数、每镜新信息和最终停留；需要更可靠的专业成片时，同时给出参考音频/参考剪辑或分段生成后剪辑的备选路线。具体规则读取 [commercial-montage.md](references/commercial-montage.md)。

### 5. 编译三个版本

除非用户要求“只给一个”或“只要提示词”，默认提供三个彼此独立、都能直接复制的版本：

1. **稳定执行版**：最低必要密度、动作因果最清楚；广告可用 4–5 个镜头，但不追求极限快切。
2. **导演增强版**：加入有动机的调度、景别阶梯、剪辑节拍、灯光和声音；纯产品/低风险广告可使用 6–9 镜头，人物与产品高风险接触广告优先使用 4–5 镜头和更完整的连续表演。
3. **创意实验版**：只增加一个受控的形式创意，如视角反转、材质匹配切、声音先行或空间错觉；不得同时堆叠多个噱头。

不要只替换几个形容词来伪造三个版本。三个版本应在镜头策略或叙事入口上真正不同，同时守住同一主体、目标和限制。

### 6. 做静态预检

生成复杂提示词后运行：

```bash
python scripts/validate_prompt.py prompt.txt --duration 10 --mode multimodal --images 2 --videos 1 --audios 0
```

也可使用 `--text` 直接传入提示词。修复所有错误；逐条判断警告是否适用。验证器只能发现静态风险，不能保证生成质量。

以下情况必须预检：两个及以上参考素材、三个及以上镜头、视频编辑/延长、对白、卡点或用户要求严格交付。高密度广告还要检查是否明确“独立切镜”、是否有剪辑/声音触发点、是否给英雄镜头留出停留。人物与道具接触还要检查道具尺寸、接触手、动作终点、下一镜开场、延迟反应和参考图姿势污染。广告和直发内容还要检查是否有与品牌匹配的纯音乐、与可见动作同步的拟音、环境底声、音乐闪避和干净声音结尾。简单单镜头可按同一检查表人工核对。

### 7. 处理失败结果

先实际查看用户给出的成片；按时间抽帧并记录真实切点、最长无新信息区间、产品清晰露出、人物/产品一致性和音画重拍。再把问题归类为身份/产品、动作物理、镜头合并、时序、声音、文字或连续性，只修改最小失败变量。读取 [repair-guide.md](references/repair-guide.md)。用户给出生成视频时，以视频真实画面和真实结尾为事实来源，不沿用原提示词设想。

## 输出格式

用户没有指定格式时，按以下顺序输出：

1. `理解与默认`：一句话复述，并列出真正影响结果的默认值。
2. `建议设置`：模式、版本、时长、画幅、声音意图；不确定的平台字段标为待确认。
3. `稳定执行版`：独立代码块中的完整提示词。
4. `导演增强版`：独立代码块中的完整提示词。
5. `创意实验版`：独立代码块中的完整提示词。
6. `素材上传顺序`：仅在使用素材时给出编号、别名、任务和禁止迁移项。
7. `预检`：只列实质性假设、风险与修复建议，不写提示词教程。

用户说“只要提示词”时，只输出一个最终代码块，不加标题、解释、教程、其他版本或追问。

所有可投喂即梦的最终提示词都必须放进独立的纯文本代码块，并在代码块前标注 `一键复制提示词`，让对话界面显示内置复制按钮。代码块内部只放完整提示词，不混入设置、风险说明、引用链接或教学文字。多个版本各用一个完整代码块，不把多个版本塞进同一块；提示词文件只作为备份链接，不能代替对话中的一键复制代码块。

广告、短剧、动作、风景、UGC、MV 等具体路线读取 [specialized-playbooks.md](references/specialized-playbooks.md)。需要校准成品质量或学习输出形状时读取 [examples.md](references/examples.md)，不要机械复制示例内容。

## 交付检查表

- 开头先出现主体和主动作，而不是一串风格词。
- 每个镜头有清楚的初始状态、触发、变化和终点。
- 有人物/道具交互时记录上一镜终点与下一镜起点；手、道具、咬痕、包装开合和视线不能在切镜后无故重置。
- 吃喝和脸部接触写明一口大小、接触方向和动作后的手部回落；不用“立刻闭眼＋放松＋呼气＋微笑”代替真实表演过程。
- 每镜头不超过一个主运镜；固定机位不与推拉摇移冲突。
- 镜头数与所选密度路线相称；商业快切主要使用低负担微距/姿态镜头，不用多个复杂事件伪装快节奏。
- 五镜头以上明确写出独立切镜、相邻景别差异、切点触发和最终英雄停留；不要让中段一个慢镜占据全片近半时长。
- 光线来自具体光源，声音与画面节拍有关系。
- 默认配乐为与产品气质匹配的纯音乐，明确速度、能量和2–4种核心乐器；除非用户要求，不出现歌词、人声演唱、哼唱或模仿具体歌曲/艺人。
- 只给真实可见的动作配置拟音；门锁、钥匙、脚步、包装、倒液体、咬断、衣料和产品落台等声音必须与接触瞬间同步，并匹配镜头距离和空间混响。
- 关键拟音出现时配乐轻微下压，不让所有音效一样响；结尾音乐与产品英雄画面共同收束，不突然截断。
- 用户要求“无需剪辑直接发布”时，提示词仍不得承诺生成结果必然达到商业响度、准确Logo/文字或平台审核标准；把它作为一次生成目标并明确剩余随机风险。
- 所有引用编号存在、连续、有别名、有任务。
- 参考视频借运镜时，不默认借走人物、场景、色彩和音频。
- 字幕、Logo、对白和“不要文字”等约束不互相冲突。
- 产品名称、卖点、Slogan 和品牌声明没有被凭空编造。
- 最终提示词是自然语言拍摄指令，不是解释 Seedance 的教程。
- 最终提示词已放在独立代码块中，可用右上角复制按钮一次复制全文；文件链接仅作备份。
