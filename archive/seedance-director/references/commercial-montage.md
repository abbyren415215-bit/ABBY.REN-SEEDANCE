# 商业卡点蒙太奇

用于 10–15 秒品牌广告、产品片、时尚片、预告和 MV。目标不是单纯增加镜头，而是让每次切镜都增加欲望、证明、节奏或记忆。

## 先判断是否适合单次高密度生成

适合 `6–9 镜头/15 秒`：同一人物、同一产品、同一地点或同一视觉世界；多数镜头是纯产品、静态姿态、液体、材质或环境插入；动作能在一眼内读懂；允许切点有少量漂移。

人物需要吃、喝、咬、涂抹、穿戴或进行嘴部/脸部接触时，不套用 6–9 镜头上限。读取 [performance-continuity.md](performance-continuity.md)，优先 4–5 镜头并保留一段连续表演。

不适合：多个地点、换装、复杂拿取/喷涂/拆装、多人互动、精确包装文字、逐帧对齐或每镜都要求复杂运镜。改用产品图/分镜板/节奏参考视频，或分成 2–4 次生成后在剪辑软件中卡点。

不要把“镜头”和“事件”混为一谈。一次喷香水是一个主事件，可以从瓶盖、手指、雾滴、女主反应和产品英雄构图获得多个镜头；但入口、吞咽、脸部涂抹等连续表演不能拆成多个静态姿势。让女主走路、拿瓶、开盖、喷洒、转身、换地点同样属于多个高负担事件。

## 商业节奏骨架

15 秒默认保留 2–3 秒英雄收尾，其余采用不均匀节奏。优先选择一种：

- 奢华递进：`1.5s 建立 → 1.2s 人物 → 0.8s 产品 → 0.7s 触感 → 0.8s 使用 → 1.0s 反应 → 1.2s 环境回响 → 2.5s 英雄收尾`。
- 重拍爆发：`2s 钩子 → 1s → 1s → 0.7s → 0.7s → 1.1s → 0.5s 留白 → 2.5s 英雄收尾`。
- 材质诗意：`环境大全景 → 人物中近景 → 产品微距 → 使用动作 → 材质/液体微距 → 人物余韵 → 产品英雄镜头`。

时间只是目标节奏。输出给即梦时使用 `镜头N（约X–Y秒，切法）`，不要写逐帧保证。不要等分所有镜头；快—快—留白—英雄停留比机械的一秒一切更像广告。

## 镜头卡

每个短镜头内部至少决定：

1. 功能：钩子、世界、欲望、揭示、触感、使用、反应、证明或英雄收尾。
2. 景别与视角：大全景/中景/近景/极近微距，正面/侧面/俯视/低机位；相邻镜头至少改变一项。
3. 一个动作：抬眼、按下喷头、雾滴穿光、布料掠过、瓶身落台等。
4. 切点：动作完成、遮挡扫过、光斑充满画面、匹配形状、重拍或短暂静音。
5. 声音：每镜最多一个主声音锚点；不要用一段笼统的“高级音乐”承担全部节奏。
6. 连续性：女主、服装、产品几何/颜色、光向和空间方向保持一致。
7. 交接：上一镜结束时的手位、道具方向与状态，是否与本镜开场完全承接。

删掉没有新信息的镜头。同一慢动作换三个近似角度不算三次有效推进。

## 防止镜头被合并

五镜头以上或已经出现“中段一个长慢镜”时，在提示词开头加入简短剪辑契约：

```text
明确的7镜头商业蒙太奇；每个镜头采用独立构图并以清楚硬切分开，不合并为连续长镜头。保持同一女主、同一件产品、同一地点和统一落日光向；每次切镜都带来新的景别、动作细节或产品信息，最后2–3秒停在产品英雄构图。
```

随后逐镜写，且让每条句子在动作已经完成的位置结束。不要在镜头末尾写“随后/接着”，否则模型容易把它解释成连续运镜。

## 景别阶梯与产品记忆

高级产品广告常用的可执行顺序：

`场景钩子（大全景） → 人物欲望（中近景） → 产品揭示（特写） → 接触触发（极近微距） → 感官证明（材质/VFX） → 人物余韵（近景） → 产品英雄收尾（正面或三分之四角度）`

产品至少在开场钩子之后尽早出现一次，中段用一个材质/使用镜头证明价值，结尾清楚停留。没有产品参考图时只定义无文字包装或通用几何，不虚构可读 Logo；正式品牌广告优先上传产品图。

## 用声音当剪辑时钟

- 有 `@音频1`：只指定它提供速度、重拍或段落能量中的一项；把可见事件逐一绑定到可听重拍，不默认复制旋律、歌词或表演身份。
- 有 `@视频1`：可以只借硬切密度、镜头长短变化和转场触发；明确不迁移人物、产品、地点、色彩和原声。
- 无参考音频：设计少量清楚的音画触发，如瓶盖轻响、喷雾瞬态、布料掠过、玻璃落台、音乐抽空与最后低频落点。要求切镜落在这些声音或配乐重拍上，但不承诺逐帧对齐。

## 专业可靠性阶梯

1. **单次纯文生视频**：最快；高密度切镜和产品一致性具有随机性。
2. **产品图 + 节奏音频/剪辑视频**：让图片锁产品，让音视频只控制节奏，通常更接近广告剪辑。
3. **分镜板/多张关键帧 + 节奏参考**：为 6–9 个构图提供视觉锚点，减少模型自行合并镜头。
4. **分段生成后剪辑**：对品牌、Logo、逐拍节奏和客户交付最可靠；每段生成 1–3 个镜头，后期完成硬切、声音和文字。

用户只要一个即梦提示词时仍应给可直接复制的单次版本；在预检中简短标出它属于哪一级可靠性。

## 成片复盘

按固定间隔抽帧并定位视觉切点，记录：实际镜头数、每镜持续时间、最长无新信息区间、产品首次出现与清晰停留、女主/产品漂移。能分析音轨时，再记录强起音或重拍是否对应切镜；不能听取或分析时明确说明。

常见最小修复：

- 只有 2–3 个大段落：加入剪辑契约，逐一编号 6–8 个独立镜头，把中段动作拆为多个低负担插入镜头。
- 有音乐节拍但画面不切：把每个关键切点绑定到具体动作声/重拍，并写明硬切，而不是只写“配乐卡点”。
- 切得快但像素材拼盘：统一人物、产品、地点、光向和一个视觉母题；在高潮前加入一次短暂停顿。
- 产品出现太晚：把产品揭示移到前 2–4 秒，并在末尾保留 2–3 秒英雄构图。
