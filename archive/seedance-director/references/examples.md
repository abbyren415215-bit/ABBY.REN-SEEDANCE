# 原创输出示例

示例只用于校准结构和密度，不要复制人物、场景或句子。

## 示例一：一句意境，纯文生视频

用户输入：

> 一个人深夜回家，走到门口才发现屋里还留着一盏灯，想要那种很克制的温暖。

内部决定：10 秒、16:9、两镜头、无对白。转折不是大哭，而是开门前握住钥匙的手停了一下。

稳定执行版形状：

```text
深夜的旧公寓走廊，一名疲惫的上班族提着折伞走到自家门口，发现门缝透出一线暖黄灯光。镜头1：中景横向跟随他走近，走廊只有冷白顶灯和远处雨声；他拿出钥匙，看到暖光后动作放慢。镜头2：切到手部近景，他握着钥匙停顿片刻，肩膀轻轻放松，再把钥匙插进锁孔。室内传来很轻的水壶声，镜头停在冷色走廊与暖色门缝之间。写实生活电影质感，表演克制，动作自然，画面无字幕。
```

为什么有效：主体、触发、可见变化和终点清楚；暖意由门缝光与水壶声承担，没有依赖“感人、治愈”等抽象形容词。

## 示例二：产品图生成高级展示

用户输入：

> 我有一张黑色香水瓶产品图，想做高级、神秘的竖屏广告。

素材绑定形状：

```text
@图片1（黑色香水瓶）只锁定瓶身几何、黑色玻璃材质、瓶盖比例、标签和Logo位置；不迁移原图背景。
```

导演增强版形状：

```text
@图片1（黑色香水瓶）只锁定瓶身几何、黑色玻璃材质、瓶盖比例、标签和Logo位置，不迁移原图背景。竖屏暗色影棚中，香水瓶位于潮湿黑石台面中央。镜头1：微距低机位缓慢横移，狭窄冷白侧光掠过瓶身边缘，玻璃先几乎隐入黑暗，随后轮廓逐步显现；台面水珠产生真实折射。镜头2：镜头停下，一束很细的暖金背光穿过瓶肩，雾气在瓶后缓慢分开，最终形成完整正面英雄构图。声音只有低频空间氛围、细小水滴和玻璃轻响。产品全程保持同一件，瓶身、标签和Logo位置不变化，无额外文字、无复制产品。
```

## 示例三：参考人物图和运镜视频

用户输入：

> 图1是女主，视频1的运镜很好。我想让她穿过一个雨夜车站，最后回头看一眼。

素材规划：

```text
@图片1（女主）控制脸部、短发、灰色风衣和年龄感，不迁移背景与姿势。
@视频1（运镜参考）只控制贴近人物的横向跟拍路径和缓慢减速节奏，不迁移原视频人物、服装、场景、色彩与声音。
```

提示词形状：

```text
@图片1（女主）锁定脸部、短发、灰色风衣和年龄感，不迁移原图背景与姿势。@视频1（运镜参考）只采用贴近人物的横向跟拍路径和缓慢减速节奏，不迁移其中人物、服装、场景、色彩和声音。雨夜火车站站台，女主沿黄色安全线快步向出口走，手里攥着一张被雨打湿的车票。镜头以@视频1的横向跟拍贴近她的侧面，随着她听见远处一声列车鸣笛而逐渐减速；她先停步，没有立刻回头，只把车票折紧，随后缓慢回头望向空荡站台。冷蓝雨光与车厢残留暖光交错，雨声、鞋底积水声和远处鸣笛清晰，镜头停在她克制的侧脸和手中折皱的车票上。人物身份、发型和风衣始终一致，画面无字幕。
```

## 反例：堆叠型提示词

```text
史诗、电影级、梦幻、真实、8K、超高清，一个女人跑步、哭泣、回头、跌倒、站起，镜头推拉摇移环绕航拍，灯光高级，音乐震撼。
```

问题：风格冲突、五个主动作、多个主运镜、没有场景因果和终点，`8K` 也不能代替平台设置。

## 示例四：15秒高级产品卡点广告

用户输入：

> 蓝色香水、女主、爱琴海、奢华品牌感，15秒；上一次生成只有三个慢镜头。

导演增强版形状：

```text
明确的7镜头商业蒙太奇；每个镜头采用独立构图并以清楚硬切分开，不合并为连续长镜头。保持同一成年女主、同一只钴蓝色矩形玻璃香水瓶、同一爱琴海悬崖露台和统一落日侧逆光；最后约3秒停在产品英雄构图。镜头1（约0–1.5秒，硬切）：极低机位大全景，白色露台边缘掠过前景，女主与海面落日形成剪影，低频第一拍。镜头2（约1.5–3秒，动作切）：中近景，女主抬起香水瓶至锁骨高度，白色丝裙被海风掀起，瓶身第一次清楚露出。镜头3（约3–4.2秒，匹配切）：100mm微距，太阳圆斑与蓝色瓶肩形状重合，银色瓶盖发出清脆轻响。镜头4（约4.2–5.3秒，重拍硬切）：极近特写，右手食指一次按下喷头，雾滴在逆光中爆开。镜头5（约5.3–7秒，材质切）：微距侧拍，蓝色玻璃中的折射像爱琴海波纹掠过瓶壁，画面只发生一次流光变化。镜头6（约7–10.5秒，先留白后切）：女主侧脸近景，闭眼停半拍，海风带走喷雾；配乐短暂抽空，只保留风声与呼吸。镜头7（约10.5–15秒，英雄收尾）：硬切到香水瓶完整正面三分之四英雄构图，瓶子立在白石台面，落日金边穿过钴蓝玻璃，镜头极慢推近后停住，最后低频落点与玻璃轻响同步。蓝、象牙白、银色、少量落日金统一全片；产品不复制、不变形，瓶盖与瓶身比例一致，画面无字幕、无额外Logo、无可读品牌文字。
```

为什么比“三幕三镜头”更有效：仍然只有“女主使用香水并留下感官余韵”一个主事件，但用环境、产品、触感、使用、材质、反应和英雄构图七个独立视点建立广告节奏；快镜头之间加入短暂静音，结尾仍有足够产品停留。
