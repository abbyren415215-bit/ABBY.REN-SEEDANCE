# 废片诊断与最小修复

## 原则

先判断成片中哪些部分已经成功。一次重试只改一个主要变量；不要为了修手部，同时重写镜头、光线、服装和对白。

无法实际查看视频时，请用户描述“哪一秒、哪个主体、期望什么、实际发生什么”，不要假装观察过成片。

## 决策顺序

1. **保留**：核心事件和主体正确，小瑕疵不影响使用。
2. **后期修**：文字、轻微节奏、裁切、声音大小、短暂瑕疵可在剪辑中解决。
3. **局部编辑**：已有视频大部分正确，只需替换/删除/增加一个元素。
4. **重抽**：提示词合理但随机结果不佳；保持提示词，只重新生成。
5. **重写**：动作不可读、素材职责冲突、镜头过载或开场/终点不清楚。

## 症状 → 根因 → 修复

| 症状 | 常见根因 | 最小修复 |
|---|---|---|
| 人物脸漂移 | 多个身份来源、镜头太多、强转身/遮挡 | 只保留一个身份权威图；减少切镜；重复2–3个稳定特征 |
| 产品变形或标签乱 | 产品动作过多、图像角色不明确、依赖模型生成文字 | 明确产品图只控制几何/材质/标签；减少旋转/拆解；文字后期加 |
| 手部或接触异常 | 一镜多动作、接触点/方向不清楚 | 写清哪只手、接触哪里、施力方向和结束姿势；删掉次要动作 |
| 运镜乱或眩晕 | 同一镜头叠加推拉摇移环绕 | 只保留一个主运镜并写停止点 |
| 计划了很多镜头但成片只有2–3段 | 镜头标记不够明确、每段用“随后”连成连续动作、没有独立构图/硬切契约 | 在开头声明明确镜头数与独立硬切；每镜用新景别和一个已完成动作；删掉跨镜连接词 |
| 中段一个慢镜占全片近半 | 三幕被误写成三个长镜头、产品证明没有拆成插入镜头 | 保留同一主事件，把中段拆成产品、手指、喷雾/材质、人物反应等低负担短镜头；为结尾保留2–3秒 |
| 有明显音乐脉冲但切镜不跟拍 | 只写“卡点”，没有把声音与可见动作逐一绑定 | 将瓶盖、喷雾、转身、落台等事件分别绑定重拍/动作声，并明确硬切 |
| 节奏赶、事件没完成 | 镜头/动作超过时长容量 | 删除最低优先级事件，或拆成连续片段 |
| 情绪假、像摆拍 | 只写抽象情绪，没有可见行为 | 用一个克制动作、视线和停顿替代“非常悲伤/激动” |
| 吃喝时像广告假笑、闭眼定格 | 同时堆叠闭眼、放松、呼气、满足微笑；没有触发后的反应延迟 | 眼睛先保持睁开；接触完成后让手下降、视线转移、吞咽，最后才出现轻微笑意 |
| 食物与嘴部接触僵硬 | 食物过大、形状不稳定、连续入口被拆成多镜头 | 改为一口大小；用一个3–5秒连续镜头完成送入口、咬下和手部回落 |
| 前半段跳切、后半段僵住 | 高风险表演仍按高密度蒙太奇规划 | 从6–9镜头降到4–5镜头；把节省的时长给连续动作和延迟反应 |
| 切镜后手和道具位置重置 | 只写每镜内容，没有记录上一镜终点和下一镜起点 | 为每个交互镜头写开场状态、结束状态与承接状态 |
| 画面很“AI” | 形容词堆叠、物理反馈缺失、风格互相冲突 | 保留一个视觉体系；加入重量、惯性、遮挡、环境响应和真实声 |
| 参考视频污染人物/色彩/声音 | 没写参考素材的禁止迁移项 | 明确视频只提供运镜/动作/节奏，并逐项排除其他维度 |
| 对白和口型不稳 | 句子过长、多角色抢话、动作同时复杂 | 缩短为一句；一次只让一个人说；降低镜头和动作复杂度 |
| 意外字幕/Logo | 对白触发文字或约束冲突 | 明确“画面无字幕”；需要准确文字则移到后期 |
| 延长段重新播放旧动作 | 续写依赖计划结尾而非真实结尾 | 记录真实边界状态；明确“已完成动作不重复” |

## 修复输出

按以下顺序返回：

1. `最可能根因`：一句话。
2. `保留不动`：列出已经成功的维度。
3. `本次只改`：一个主要变量。
4. `修复后提示词`：完整可复制版本。
5. `判断标准`：下一次只检查这个变量是否改善。
