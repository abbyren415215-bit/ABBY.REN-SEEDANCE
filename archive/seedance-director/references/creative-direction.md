# 从意境到导演指令

## 目录

- 判断创作类型

## 判断创作类型

先选一条主线：

- **叙事/表演**：人物在片段中有目标、阻力或认知变化。
- **产品/功能**：观众需要看清外形、材质、卖点或使用结果。
- **环境/氛围**：空间、天气、光线或节奏本身是主体。
- **动作/VFX**：因果、接触、重量和运动方向是成功关键。
- **编辑/延长**：已有视频是事实来源，新提示词只改变或继续指定部分。

每次生成只选一个第一优先级。其他诉求服务于它。

## 导演读取

叙事或表演内容在内部回答六件事，不把字段名写进最终提示词：

1. 片段作用：建立、揭示、告别、反转、释放、悬念或兑现。
2. 可见转折：开始和结尾有什么可以被镜头看见的差异。
3. 人物目标：这一刻想得到、隐藏、逃离或确认什么。
4. 克制动作：一个身体细节代替抽象情绪，例如手指停在门把上、吞回一句话、把折好的纸再次压平。
5. 不可替代细节：只属于这个场景的具体物件、声音或行为。
6. 拒绝套路：明确不用最容易的库存答案，例如悲伤不等于立刻大哭，惊悚不等于突然扑脸。

把读取结果转换成可见或可听的载体：站位、视线、手势、道具、空间距离、镜头终点、声音出现/消失和具体光源。

产品、抽象视觉和纯环境片不要虚构人物欲望，只回答：`要让观众看清什么` 与 `不采用什么俗套展示`。

## 情绪翻译

| 用户感受 | 可执行的导演选择 |
|---|---|
| 温暖、治愈 | 接近人物高度的中近景；窗光或夕阳；缓慢靠近；保留呼吸、衣料和室内底噪 |
| 孤独、疏离 | 人物位于画面边缘；较大负空间；固定或极慢移动；远处环境声压过对白 |
| 紧张、压迫 | 受限构图；遮挡或门框；缓慢逼近；先出现离屏声音，再出现原因 |
| 浪漫、暧昧 | 不直接拥抱；用视线回避、距离缩短和迟疑动作；柔和侧逆光；减少台词 |
| 史诗、壮阔 | 先建立尺度关系；主体只完成一个决定性动作；镜头运动跟随力量方向；声音逐层扩大 |
| 高级、商业 | 单一主光塑造材质；背景整洁但非空洞；受控移动；结尾停在清楚的英雄构图 |
| 真实、UGC | 人体驱动的轻微手持；自然重构图和曝光变化；生活化环境声；允许小停顿与不完美 |
| 梦境、超现实 | 只引入一条不可能规则，例如重力倒转或空间折叠；其他物理表现保持可信 |
| 幽默 | 固定观察、延迟反应、一个荒谬但清楚的事件、短促单一音效；不要用快切掩盖笑点 |

不要把表中所有元素都塞入同一个提示词。选择一个镜头、一个光线逻辑和一个声音策略。

## 动作与镜头

### 动作链

复杂动作按顺序写：

`初始状态 → 触发 → 决定性变化 → 反应 → 余波 → 可见终点`

每个镜头只覆盖其中一到两个环节。接触动作要写清：谁接触什么、方向、力度、重量反馈、遮挡和恢复动作。

### 一个镜头一个主运镜

- 固定机位：适合表演、幽默、产品动作验证。
- 缓慢推近：适合意识、压力或亲密感逐渐集中。
- 缓慢拉远：适合失落、揭示环境规模或结束关系。
- 横向跟拍：适合行走、追踪和空间连续性。
- 环绕：适合展示立体关系或力量聚集；不要与多种推拉摇移同时叠加。
- 手持跟随：适合现场感和不稳定情绪；不要同时要求绝对稳定的广告机位。
- 主观视角：适合沉浸，但必须说明视线目标和身体/道具是否入画。

镜头只因为故事需要而动。写清镜头何时停止，以及停止时观众应看到什么。

## 灯光与声音

### 灯光

写具体来源和作用：窗外阴天、货架冷光、台灯暖光、车辆扫过的灯、屏幕反射、落日侧逆光。避免只写“电影级灯光”。

### 声音

声音最多选三层：

1. 环境底噪：雨、空调、街道、风、空间混响。
2. 同期动作声：脚步、呼吸、布料、金属、液体、机械。
3. 音乐或对白：只在它推动转折时加入。

让声音参与叙事。例如：电梯提示音先响，人物才抬头；音乐在手松开时停止；风声在门关闭后突然变闷。

## 密度和取舍

优先顺序：

1. 主体身份或产品外形。
2. 主动作和可见终点。
3. 参考素材角色与连续性。
4. 一个主运镜。
5. 具体光源。
6. 关键声音。
7. 风格、色彩和装饰细节。

如果提示词要求所有东西都同样重要，它实际上没有优先级。先删装饰，再删次要动作，最后才考虑拆成两段。
