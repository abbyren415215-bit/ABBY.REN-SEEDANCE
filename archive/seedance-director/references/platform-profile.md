# Seedance 2.0 平台档案

最后核对：2026-08-15。平台能力可能变化；用户询问当前价格、配额、地区、模型 ID、分辨率或接口字段时，重新查询对应平台官方资料，不要只依赖本文件。

## 权威边界

- 字节 Seed 官方发布页确认 Seedance 2.0 支持文字、图片、视频、音频输入；单次可同时输入最多 9 张图片、3 段视频、3 段音频，并支持最长 15 秒的多镜头音视频输出。
- BytePlus 官方提示词指南建议复杂视频采用 `Shot 1 / Shot 2 / Shot 3` 的镜头顺序；它同时指出 `0–3 秒` 一类精确时间控制并不稳定。
- BytePlus API 文档把严格首帧、严格首尾帧、全能参考列为互斥的传输场景。提示词可以表达“接近某个首尾画面”，但不能代替严格的 `first_frame` / `last_frame` 角色。
- 官方发布页提示：使用真人肖像作为主体参考需要身份验证或事先合法授权。

## 模型版本守卫

本档案只约束 Seedance 2.0。用户使用 2.5、Mini、Fast、其他提供商重命名版本或未知版本时：

1. 保留镜头、动作、光线、声音、连续性和素材分工方法。
2. 不照搬本档案的时长、分辨率、素材上限、模型 ID 或接口字段。
3. 提示用户在当前界面确认版本和可选参数；需要精确操作时再查官方文档。

## 即梦中文引用

默认写法：

- 图片：`@图片1`、`@图片2`
- 视频：`@视频1`、`@视频2`
- 音频：`@音频1`、`@音频2`

平台的可视引用标签比手写字符串更权威。用户提供的标签必须逐字保留，不翻译、不改空格、不重新编号。

编号后立即加入别名和任务：

```text
@图片1（女主形象）只锁定脸部、发型和服装。
@视频1（运镜参考）只采用横向跟拍路径和剪辑节奏，不迁移人物、场景、色彩和声音。
@音频1（音色参考）只采用女声的低沉音色，不复用原文内容。
```

## 模式区别

| 模式 | 输入含义 | 提示词重点 |
|---|---|---|
| 文生视频 | 没有参考素材 | 主体、动作、环境、镜头、光线、声音、终点 |
| 严格首帧 | 图片是准确开场 | 不重新发明构图；描述从该画面开始怎样运动 |
| 严格首尾帧 | 两张图片是准确端点 | 描述连续变化路径，避免中途增加无关事件 |
| 全能参考 | 素材提供身份、产品、环境、动作、运镜、节奏或声音 | 给每个素材一个主要任务和禁止迁移项 |
| 视频编辑 | 在原视频上改变一个目标 | 明确改变对象和必须保持的原片内容 |
| 视频延长 | 从原视频真实边界继续 | 先记录真实边界状态，再写新动作与新终点 |

## 设置与提示词分离

把以下内容放在建议设置中，并以当前界面为准：模型版本、生成时长、画幅、分辨率、声音开关、水印或导出选项。

提示词只保留会改变画面或声音的创作信息。不要把 `4K`、`8K`、`顶级质量` 当作分辨率设置，也不要把不存在的 `seed`、`camera_fixed` 等 API 字段塞进自然语言提示词。

## 保守写法

- 使用少量正向约束：`人物五官、发型和服装保持一致；动作接触自然；画面无额外文字。`
- 不堆砌长篇负面词墙。
- 不承诺对白、字幕、Logo、手指、逐帧时间点或人物一致性绝对准确。
- 需要准确文字、包装说明、价格或法律声明时，优先建议后期添加。
