# 一次生成的音乐与拟音设计

用于所有带声音的视频，尤其是品牌广告、产品片、UGC、社交短片和用户要求“生成后无需剪辑直接发布”的任务。目标是让声音参与叙事和品牌塑造，而不是在提示词末尾追加一句“配高级音乐”。

## 三层声音架构

按以下优先级设计，不要求每个瞬间三层都同时存在：

1. **动作拟音/SFX**：与画面接触点同步，承担真实感和剪辑触发。
2. **纯音乐/BGM**：承担品牌气质、速度、情绪递进和结尾收束。
3. **环境底声/Ambience**：建立房间、街道、海边、商店或户外的空间尺度。

用户把开门声、咬断声、钥匙落桌声称为“配音”时，按动作拟音处理；旁白、人物对白与口播必须由用户明确提出，不能自行添加。

## 先为产品选择纯音乐

默认使用原创感纯音乐：无歌词、无人声演唱、无哼唱、无可辨识歌曲旋律，不模仿具体歌曲或艺人。用速度、能量曲线和2–4种核心乐器描述，不堆砌流派。

| 产品/内容气质 | 建议音乐语言 | 避免 |
|---|---|---|
| 奢侈品、香水、珠宝 | 低速极简钢琴、稀疏柔弦、玻璃质感音色、克制低频 | 俗套宏大管弦、强鼓点、过甜旋律 |
| 巧克力、咖啡、甜点 | 暖色毡音钢琴、轻柔弦乐、木质敲击、圆润低音 | 夸张可爱音效、过度爵士化、湿黏口腔声 |
| 美妆、护肤 | 空气感合成器、轻电子脉冲、柔和钢琴、细小闪光音色 | 密集高频、强烈夜店节拍 |
| 科技、汽车 | 克制电子脉冲、低频节奏、金属质感打击、渐进合成器 | 无动机轰鸣、每镜都用冲击音 |
| 家居、生活方式 | 轻木吉他、毡音钢琴、柔和手鼓或刷奏 | 儿童化旋律、模板化企业音乐 |
| 悬疑、剧情 | 低音持续音、稀疏脉冲、有限不协和音 | 用突发巨响代替悬念 |

音乐结构要跟随视频结构：开场少量声部，中段因产品接触或情绪变化增加一层，英雄收尾形成短而完整的和声终止或自然尾音。不要让音乐从头到尾同一强度。

## 为可见动作选择拟音

每个镜头最多设一个主拟音锚点，辅助声音保持低调。声音只能来自画面内或合理画外声，并与动作接触帧同步。

| 可见动作 | 合适拟音 | 控制重点 |
|---|---|---|
| 开门/关门 | 锁舌轻响、把手回弹、门轴与房间声变化 | 材质与空间匹配，不用夸张撞门 |
| 放下钥匙 | 金属钥匙碰木桌/石材托盘的短促清响 | 声音材质、重量和距离匹配 |
| 脚步/坐下 | 鞋底、地板、沙发布料和坐垫轻微压缩声 | 不要每一步都同样响 |
| 开盒/拆包装 | 纸张摩擦、盒盖阻尼、托纸轻响 | 与手指触碰和开合终点同步 |
| 巧克力入口 | 一次细小咬断或脆裂声、低量自然咀嚼 | 避免放大湿黏口腔声和ASMR式夸张 |
| 倒饮料 | 连续液体流声、杯壁轻响、落杯声 | 液体开始/停止与画面一致 |
| 香水/喷雾 | 喷头机械轻响、短促细雾声 | 不用爆炸式气流声 |
| 产品落台 | 与玻璃、金属、木材或石材匹配的接触声 | 体现重量，不制造不合理回响 |

不为画面中没有发生的动作添加声音。例如人物没有开门，就不写开门声；没有钥匙，就不写钥匙声。宁可少而准，不要把音效列表当作声音设计。

## 音画同步与混音

- 把切镜绑定到具体声音：锁舌、包装摩擦、咬断、杯子落台、音乐低音或短暂停顿。
- 关键拟音出现时让背景音乐短暂轻微下压，拟音结束后平滑恢复；不要用音乐盖住产品接触声。
- 近景拟音更清楚、更干；远景更轻并带空间混响。声音方位与画面左右位置一致。
- 环境底声保持连续，切换景别时只改变远近，不在切镜处突然消失。
- 不让所有音效一样响。每段只保留一个听觉焦点，其他声音退后。
- 对话、旁白、音乐和拟音不能同时争抢中心；没有明确传播文案时，优先音乐＋拟音，不主动添加旁白。

## 直发型结尾

用户要求“生成后直接发布”时，在提示词中明确：

1. 开头0.3–0.5秒不爆音，音乐自然进入。
2. 关键动作声清楚但不过载，无突然音量跳变、失真或刺耳高频。
3. 最后产品/结论画面停留时，音乐形成短和声终止，环境尾音自然衰减，不突然截断。
4. 无用户未要求的歌词、旁白、字幕、价格、促销声明或额外品牌声音标识。
5. 若平台允许，开启音频生成；有参考音频时先绑定它控制节奏、音色或旋律结构中的哪一项。

一次生成只能以“尽量直发”为目标。模型生成的品牌文字、口型、响度、峰值和平台审核适配仍有随机性；正式商业投放应复核，不能承诺绝对零后期。

## 可复制声音段落骨架

```text
【声音设计】使用与[产品/情绪]匹配的原创感纯音乐：[速度]，[2–4种乐器]，[能量曲线]；无歌词、无人声演唱、无哼唱，不模仿具体歌曲或艺人。环境底声为[空间底声]。只为画面中真实发生的动作加入同步拟音：[动作→声音]；每镜一个主拟音，匹配材质、距离和空间混响。关键拟音出现时配乐轻微下压，随后平滑恢复。开头自然进入，结尾在[英雄画面/终局动作]形成短和声终止并保留自然尾音，无爆音、突然截断或无关旁白。
```
