## 内部简报

生成前先形成以下对象，不必原样展示给用户：

```text
目标：
模式：
主体与不可变特征：
开场状态：
主事件与可见终点：
场景与空间关系：
情绪/商业意图：
镜头策略：
光线来源：
声音策略：
参考素材角色：
必须保持：
允许发挥：
建议设置：
```

## 通用顺序

最终自然语言优先按以下顺序：

`主体与主动作 → 环境和空间关系 → 镜头/剪辑 → 光线和色彩 → 表演或材质 → 声音 → 少量连续性约束`

复杂片段用：

```text
【主体与参考绑定】
...

镜头1：镜头方式。主体动作。空间变化。同步声音。
镜头2：切到新的构图。因果动作。可见转折。同步声音。
镜头3：终局构图。收束动作。明确终点。声音余波。

【整体统一】
光线、色彩、质感、身份/产品/文字/连续性约束。
```

不要在每个镜头重复同一串风格词。

## 文生视频

### 单镜头

```text
[具有2–3个稳定特征的主体]在[具体环境与位置]完成[一个动作链和清楚终点]。镜头采用[景别]，[一个主运镜及停止点]。[具体光源]形成[色彩/材质效果]。[环境声、动作声或一句对白]。保持[最关键的身份、动作或画面约束]。
```

### 多镜头

使用镜头顺序，不默认硬切时间戳：

```text
镜头1：[建立状态和触发]
镜头2：[决定性变化和反应]
镜头3：[余波和可见终点]
```

每个切镜必须对应新的信息或事件，不要把同一个动作从三个角度重复一遍。

## 严格首帧与首尾帧

### 首帧

```text
以@图片1（严格首帧）作为准确开场构图。从这个画面开始，[主体别名]先[细小启动动作]，随后[主动作和方向]；[环境元素]做出自然响应。镜头[一个运动或保持固定]，曝光和光线连续。保持首帧中的人物/产品、服装、布局和背景不变，只改变[允许变化项]。最终停在[可见终点]。
```

不要重新描述并改变首帧中已经确定的主体和构图。

### 首尾帧

```text
@图片1为严格首帧，@图片2为严格尾帧。保持[共同主体和不可变特征]，从首帧的[起始状态]连续经过[一条合理变化路径]到达尾帧的[结束状态]。镜头[单一运动]，动作方向、光线和空间关系连续；不增加与这条变化无关的角色或事件。
```

## 全能参考

先绑定，后写故事：

```text
@图片1（主角）只锁定脸部、发型和服装；不迁移原图背景和姿势。
@图片2（场景）只提供建筑、空间布局和色调；不迁移其中人物。
@视频1（动作参考）只提供起身、转向和奔跑的动作节奏；不迁移人物、场景、服装和音频。
@音频1（声音参考）只提供低沉女声音色；对白内容使用本提示词。

镜头1：...
镜头2：...

人物身份和服装始终以@图片1为准，场景以@图片2为准；动作路径以@视频1为准，其他维度不从该视频迁移。
```

一个控制维度只指定一个权威来源。人物身份不能同时由两张互相冲突的图决定。

## 编辑与延长

### 编辑已有视频

```text
严格编辑@视频1（原视频）。只在[时间窗/位置]把[原元素]替换/删除/增加为[目标元素]。保持原视频中的[人物、手部接触、机位、运动轨迹、光线、反射、遮挡、背景、总时长和原声]不变。新元素必须匹配原有尺寸关系、透视、光向、运动和遮挡。
```

不要只写“参考@视频1”，否则容易变成重新生成。

### 延长

先从用户提供的视频或最后一帧记录：人物姿势、视线、道具位置、运动方向和速度、镜头高度/方向、光线、环境和声音尾巴。

```text
从@视频1真实结尾向后延长。开场严格承接：[已观察到的真实边界状态]。随后[一个新动作链]，镜头继续保持[方向/运动逻辑]，光线、色彩、空间和环境声连续。已完成的动作不重复。最终停在[新可见终点]。
```

无法查看视频时，把边界状态标记为“用户描述”，必要时只追问这一项。

## 连续片段

总时长超过单次生成容量时：

1. 先写完整故事的一句话终局。
2. 把主要事件按因果分组为片段，每段只有一个叙事任务。
3. 只把第 1 段提示词定稿；后续段先写意图卡。
4. 第 1 段生成并接受后，根据真实结尾编译第 2 段。
5. 每段保留角色、服装、空间方向、关键道具、色彩和声音状态。

不要提前假定生成结果一定停在计划姿势。

## 三版本策略

三个版本保持同一创作目标，但各用不同控制策略：

- **稳定执行版**：一个动作链、较少切镜、直接光线和声音，约束只保护关键风险。
- **导演增强版**：用人物调度、镜头终点、声音变化承载叙事转折。
- **创意实验版**：加入一个能被一句话解释清楚的形式规则；如果删掉该规则，仍应是完整可执行的视频。

禁止通过简单替换“电影感/高级感/梦幻感”制造伪差异。
