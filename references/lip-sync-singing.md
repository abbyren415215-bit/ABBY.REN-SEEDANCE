# AI对口型唱歌：逐句、克制、画外弹奏

## 适用范围与证据

用户在逐段吉他弹唱试片后，明确要求保存这套方法并自动选用。该方法以用户反馈为依据：初版叠加肩臂联动、前倾回正及琴身晃动，出现动作过大、手部入画；缩减动作并禁止扶琴、重新抱琴后，后续段落获用户认可。此为用户评价，不冒称助手已逐帧/逐音轨审核，也不保证下一次生成成功。

用于已有主图和歌曲音频的数字人/AI对口型唱歌，尤其适合吉他只露边缘的近景。不是手指演奏教学或精确和弦演示，也不是短剧对白流程。以下是已验证场景的默认值，用户当前明确要求优先；不把所有歌曲永久限制成低头、闭眼或不动。

## 自动调用与范围裁决

- 用户说“对口型唱歌、边弹边唱、下一句、闭眼陶醉”时自动从ABBY入口路由到本文件，不要求点名Skill。首次使用读取本文件；已在上下文时复用，按新反馈只改必要部分。
- 已安装参考库按 [来源与调用](film-craft-sources.md) 选取：动作过多先精简，手部入画先核对取景与道具状态，确有受光问题才查摄影。普通固定机位弹唱不调用FPV，也不为了用上技能增加运镜或动作。
- 本模式允许用户指定歌曲及其已有伴奏，声音以本段音频为准。不套用短剧无歌曲、25秒人声截止、最后5秒静默、末尾强制睁眼、16:9或前中后场景插镜；不为凑30秒压缩一整组歌词。
- 自动读取已安装文本和长度核对不等于授权上传/裁音频、改图、生成视频、付费或发布。用户明确禁止工具时只复用会话内容，不假称本轮读过技能或看过成片。

## 一次只写当前一句

1. 使用已确认的主图、当前歌词及对应音频片段，不把全部歌词写入一条。段号跟随用户进度，不自动跳段或重写已接受片段。
2. 当前数字人“动作描述”按用户实测上限500字处理，默认尽量控制在350—450字符内；计入所有实际粘贴的歌词、标点、空格与换行，不能只数汉字。该上限是当前界面反馈，不宣称所有即梦模式统一500字。能核对时核对；禁止工具时明显留余量，不虚报精确字数。
3. 交付仅一段可直接粘贴的中文动作描述，必要时外附一句“上传本句对应音频”。不塞五段式、多个方案、技术教学或额外素材清单；页面不使用@语法时不强加@绑定。
4. 音频是发音、起音、拖腔、停顿、换气和情绪峰值的依据。未试听不编秒点、节拍、调性或高潮位置；时间可写“本句起音至尾音结束”。不能把歌词中出现“呼吸”等词当作额外表演指令。

## 已接受的表演基线

**摄影与身份。** 沿用当前主图与已接受片段的画幅、脸型、五官、服装、发型、机位、光向和琴身露出比例。该场景默认竖屏胸上近景、平视固定机位、50mm自然透视，眼睛与嘴部在清楚可用的焦点内。固定镜头不再附加缓推、环绕或机位俯仰，不用“高清/焦段”保证清晰度。

**运动幅度。** 嘴唇与下颌完成必要的小幅发音，眼神和自然眨眼承担主要情绪；肩颈放松，头部、躯干和吉他位置基本稳定。取消肩臂带动、琴身联动、前倾回正、随节拍摇摆等叠加指令。稳定不等于全身冻结；只允许不抢眼的自然微动，不要求每拍发生一次。

**画外弹奏。** 主图只露局部吉他且用户不要手时，写“弹奏在画外完成，画内不展示弹奏动作”。双手、手腕和前臂保持在画面下边界外，吉他仅保留已有边缘；不露琴弦、音孔或琴颈。持续沿用既有抱琴姿态，不把“抱琴”写成新动作；重点防止抬手扶琴、重新抱琴、调整琴身和摸头发。不要又要求明确扫弦、复杂手指动作或明显身体联动。若用户以后要求可见手部/和弦，重新确认演奏目标，不声称本模式能验证准确指法。

**呼吸与口型。** 口型跟随音频起收音、辅音与元音，拖长音不反复张合嘴。只在原音频真正的换气空隙补气，长句保持连续；直接起唱的片段不强加开头吸气。不得逐句先叹气、抬肩、挺胸、深呼吸，或新增可听喘息。不把“真人感”写成夸张胸肩起伏。

**闭眼陶醉。** 用户要求时用缓缓轻闭眼、眉心舒展、面颊和嘴角放松，口型持续跟随声音；头部保持原角度，不挤眼、仰头、摇头或晃身体。闭眼可以只在一句中的指定位置，也可覆盖余下演唱；不机械地每句闭眼再睁眼。用户要求余韵闭眼时可闭眼结束，下一段承接该状态，不强制结尾睁眼。

**声音与收尾。** 仅沿用已选音频的人声、换气和已有伴奏，不叠加新歌声、吉他、BGM或音效。尾音完整唱完再收口；段末保留已确认的眼睛状态、坐姿和琴身位置，不突然扶琴或定格。无自动字幕、歌词文字、标题和水印。除非用户要求，不在提示词之外改音频或声线。

## 反馈驱动的最小修正

| 用户反馈 | 下次只调整的重点 |
|---|---|
| 动作过大、AI感强 | 删除身体与道具的联动要求，保留口型、放松目光和必要眨眼；不靠添加更多动作实现真实感 |
| 后半段手伸出扶琴 | 维持主图裁切与琴身位置，禁止抬手扶琴/重新抱琴/调整吉他；删除“收尾整理姿势”等触发动作 |
| 想更陶醉、闭眼唱 | 只增加眼皮和轻微面部情绪变化，不叠加抬头、摇摆或大幅呼吸 |
| 某段已经不错，继续下一句 | 复用摄影、裁切和动作基线，仅换当前歌词及本句必要表情，不重新创作整套动作 |
| 口型或呼吸不对 | 先核对音频片段与歌词是否匹配；未听过不伪造诊断，不靠堆表情解决同步问题 |

交付前内部核对：一句歌词、输入上限、音频驱动、固定构图、画外双手、无重新扶琴、无身体摆动、闭眼不联动头部、尾音后才收口、无字幕。禁止项围绕已出现的问题精简，不把所有可能错误堆成超长清单。提示词约束不是模型行为保证。

## 紧凑写法示例

这是结构示例，实际交付必须填入用户当前一句歌词，并按该句表情和结束状态改写，不照搬示例占位字样：

## 保存边界

本文件只保存可复用的方法和用户反馈所支持的结论。具体歌曲、歌词、人物照片、音频、视频、逐段提示词及进度默认留在工作目录，不随Skill维护公开上传。已接受成片与待生成草稿分别记录；不因用户认可上一段就将尚未测试的下一段写成“验证通过”。
