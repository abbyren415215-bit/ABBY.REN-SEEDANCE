# 人物身份与参考素材

服从[项目规则](../projects/bingbing/workflow.md)与[规则裁决](rule-precedence.md)。优先沿用已确认素材；以下卡片制作建议只在用户要求制作或确需提出建议时适用，不授权生成/修改图片或索要清单外素材。

## 多视图人物卡

用户指定“Abby人物多视图／Abby多视图”时，执行[图片生成与多视图规范](../IMAGE_GENERATION_GUIDELINES.md)：左上头顶至锁骨的大幅正脸近照、右上多表情头像、下方正侧背完整全身、右下正脸半身，不能简化成普通四宫格。仅要求“Abby三视图”时只给正侧背；明确要求普通四视图时按当次角度执行。所有版式保持同一脸、发际线、当次发型、身形、服装和鞋；统一比例、光线与中性背景，无文字、标签、边框、网格和场景。氛围版与AI风格版按对应口令独立执行。

绑定模板：

```text
[角色]对应@图片N，仅采用同一人物的身份、脸型、五官、肤色、身形、发型与服装；
多视角仅用于保持人物一致性，不生成多个[角色]，不采用图片背景和站立姿势。
```

同一次生成优先使用已确认的唯一身份参考，不挂载互相冲突的脸卡；旧单人卡退出当前引用即可，不自动删除源文件。脸与造型需要分工时，分别声明身份、服装、发型与版式的职责和“不采用”项；不得固定图一／图二顺序。每套新穿搭独立，用户要求“其他保持不变”时只改点名部分。

## `@` 绑定密度

采用两级引用：

1. 顶部逐份绑定素材的职责和排除项。
2. 素材真正出镜时，在对应时间窗再次 `@` 点名。

不要每拍重复全部素材。示例：

```text
[参考素材声明]
小晶对应@小晶四视图……
教室对应@场景……
蓝笔对应@圆珠笔……

8-12秒【笔越线】：100mm桌面微距，严格采用@圆珠笔的透明蓝色笔身；
它从@阿杰右手旁滚出，越过@场景中课桌中央的白线，停在@小晶左手旁。
```

## 场景卡

本项目按用户2026-09-21裁决，不再预制或默认挂载人物嵌入场景的站位、上下楼关系及共同持物合成图，也不把它们设为开拍前置条件。使用已确认人物、独立场景/家具及道具参考，空间、视线与接触关系由对应镜头文字明确；详见[稳定协议0.11](../projects/bingbing/production-protocol.md#011-不再预制人物站位合成图2026-09-21用户裁决)。不删除旧图，不把此偏好扩展为禁止所有图片任务；用户之后明确重新指定时再按新要求处理。

场景卡只负责建筑、空间、材质、光线、天气与固定陈设，不采用其中任何人物。若实际场景需要背景群演，在视频提示词中明确“允许并要求新增背景生态”，避免空场景图被误解为最终无人场景。

场景的新旧程度由四个变量控制：材质、维护、使用和色偏。参考图方向错误时先指出问题，图片编辑须得到用户同意；无授权时按已知可用角度设计镜头。

## 道具状态账本

符号道具优先使用现有独立卡，并记录：初始位置、持有人、物理状态、首次出现时间、每拍结束位置。第一次出现要有来源，不能凭空出现；没有独立卡时不自动生成或修改图片。

```text
折叠纸条对应@折纸，仅定义方格纸材质与折叠形态，不采用背景和任何文字。
25秒前严禁出现；25秒后由阿杰从衬衫口袋取出，完整露出后放入桌斗。
禁止替换为粉笔、橡皮、纸团或其他白色物件。
```

## 素材挂载纪律

- 出镜且有职责：挂载并绑定。
- 不出镜：删除。
- 新段独立生成且有台词：绑定已有个人音色；没有可用音色时才提出单人干净音色锚点需求，不把历史5–10秒建议当平台硬限制。
- 延长上一段：绑定母片并继承音色、姿态、道具位置和光线。

## Abby固定个人音色与自然开口（2026-09-27）

用户指定已有个人音色后，将它设为Abby唯一固定声音参考。每次有Abby发声的生成（含画内中英对白、电话声、旁白和内心独白）均实际挂载并逐句绑定，不因为写了“同一女声”就省略附件，不另生成声音锚点，不默认从前片重建或替换。纯无声片段不凭空加人声。

音色文件、备份路径、散列与实际上传标签仅留本地。文件缺失或工具不支持音频参考时说明实际限制，不假称已绑定，不擅自换声。语义别名与平台上传编号分开，提交前核对真实附件；音频在本地存在不等于上传完成。

参考只提供本人声音身份、音色与发音特征，不机械复制原文、情绪、停顿、叹气或呼吸动作。每句按剧情自然直接开口，禁止默认加句首叹气、明显吸气、拖长呼气或额外“唉”。保留正常轻微呼吸，不强迫屏息；只有用户明确指定才安排叹气。此规则同时适用于对白生成、旁白、声音参考提取与剪辑审片。

## 面部稳定与续拍参考分工（2026-09-27用户反馈）

- 用户指出前片脸型或五官漂移时，保留其已接受版本，下一条明确原始已确认人物图为唯一面部身份依据；实片帧只承接空间、衣物、姿态与物件，不继承生成的脸部偏差。不可把“同一个人”几个字当作已解决。
- 核对眼距、鼻口、下颌、发际线及各机位一致性。面部镜头采用正常摄影距离和适度角度；瘪嘴、咀嚼等表情保持小幅真实，不靠夸张拉伸、鼓腮或大幅噘嘴表达情绪。原脸型稳定不等于冻结表情。
- 不以焦段、高清词或绑定数量承诺身份稳定；交付时实际比较关键面部帧并区分用户反馈、已见偏差和待动态验收。未获授权不新造人物图、不重跑已接受视频。
