# 人物身份与参考素材

服从[项目规则](../projects/bingbing/workflow.md)与[规则裁决](rule-precedence.md)。优先沿用已确认素材；以下卡片制作建议只在用户要求制作或确需提出建议时适用，不授权生成/修改图片或索要清单外素材。

## 多视图人物卡

优先制作一张横向四视图角色卡：正面、3/4、侧面、背面。保持同一脸、发际线、发型、身形、服装和鞋；统一比例、机位、光线与中性背景；无文字、标签、边框、网格和场景。

绑定模板：

```text
[角色]对应@图片N，仅采用同一人物的身份、脸型、五官、肤色、身形、发型与服装；
多视角仅用于保持人物一致性，不生成多个[角色]，不采用图片背景和站立姿势。
```

一旦四视图卡身份正确，删除旧单人角色卡。两张脸卡并存容易被融合成第三个人。只有脸与造型确实需要分工时才临时使用双卡，并分别写清“不采用”。

## `@` 绑定密度

采用两级引用：

1. 顶部逐份绑定素材的职责和排除项。
2. 素材真正出镜时，在对应时间窗再次 `@` 点名。

不要每拍重复全部素材。示例：

```text
[参考素材声明]
小晶对应@小晶四视图……
教室对应@场景……
蓝笔对应@圆珠笔……

8-12秒【笔越线】：100mm桌面微距，严格采用@圆珠笔的透明蓝色笔身；
它从@阿杰右手旁滚出，越过@场景中课桌中央的白线，停在@小晶左手旁。
```

## 场景卡

本项目按用户2026-09-21裁决，不再预制或默认挂载人物嵌入场景的站位、上下楼关系及共同持物合成图，也不把它们设为开拍前置条件。使用已确认人物、独立场景/家具及道具参考，空间、视线与接触关系由对应镜头文字明确；详见[稳定协议0.11](../projects/bingbing/production-protocol.md#011-不再预制人物站位合成图2026-09-21用户裁决)。不删除旧图，不把此偏好扩展为禁止所有图片任务；用户之后明确重新指定时再按新要求处理。

场景卡只负责建筑、空间、材质、光线、天气与固定陈设，不采用其中任何人物。若实际场景需要背景群演，在视频提示词中明确“允许并要求新增背景生态”，避免空场景图被误解为最终无人场景。

场景的新旧程度由四个变量控制：材质、维护、使用和色偏。参考图方向错误时先指出问题，图片编辑须得到用户同意；无授权时按已知可用角度设计镜头。

## 道具状态账本

符号道具优先使用现有独立卡，并记录：初始位置、持有人、物理状态、首次出现时间、每拍结束位置。第一次出现要有来源，不能凭空出现；没有独立卡时不自动生成或修改图片。

```text
折叠纸条对应@折纸，仅定义方格纸材质与折叠形态，不采用背景和任何文字。
25秒前严禁出现；25秒后由阿杰从衬衫口袋取出，完整露出后放入桌斗。
禁止替换为粉笔、橡皮、纸团或其他白色物件。
```

## 素材挂载纪律

- 出镜且有职责：挂载并绑定。
- 不出镜：删除。
- 新段独立生成且有台词：绑定已有个人音色；没有可用音色时才提出单人干净音色锚点需求，不把历史5–10秒建议当平台硬限制。
- 延长上一段：绑定母片并继承音色、姿态、道具位置和光线。
