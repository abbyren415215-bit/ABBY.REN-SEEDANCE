# 审批制整集制作：助手执行，用户集中审批

2026-09-27最新逐段模式：用户要求先确认素材画布、每段视频单独授权并验收时，执行 [逐段审核](scene-by-scene-review.md)。本模式覆盖下文批次自动推进及默认重试；每次生成后汇报实际消耗与本集累计。素材确认、图片制作授权、视频生成授权分别记录。

最新补充按[剧本确认后自动制作与后期字幕](generated-clean-final-captioned.md)：用户先选定剧本，然后由助手自动推进制作；生成片段无BGM无字幕，剪辑定版后加校对字幕，成片仍无BGM。下文审批点是必要决策类别，不是每集强制重复三轮；既定视觉和有效预算复用，不逐份审批提示词。

2026-09-27用户将分工改为：每集约2分钟，4场各30秒，不再自己逐场上传生成，只做审批。此模式替代原半自动流程中“用户自己点击每次生成”的分工；现有素材纪律、详细提示词标准、真人表演与连续性继续执行。按当前系列使用此时长配置，不改其他已确认作品。

## 执行职责与集中决策

1. **内容与视觉审批**：助手先准备完整四场剧本、角色/场景方案、素材清单与缺项，标明现有素材、拟新增素材、已确认及待确认。用户先决定剧本；已确认视觉复用，确需改变身份或主要造型时集中给出选项。缺少实际参考图时不能声称已经视觉定稿；批准视觉方案后的必要生图按该授权范围执行，收费仍计入预算。
2. **生成计划与预算审批**：四场提示词、素材对应、连续性、实际可用入口和页面报价准备完成后，给出可复核的批次。列每场设置、生成条数、积分估算/实价、总预算上限、可用重试额度。用户批准明确范围与上限后，助手在范围内上传、填写、提交、查状态和下载；不再每场重复问同一个问题。报价未知时不得写成已获预算授权。
3. **整片审批**：助手先审四段、衔接与声音，再按顺序合成约120秒，交付整片及有时间点的问题。用户看成片，决定通过或提出修改。普通下载、检查、拼接、修整文件无需再批；新增付费生成遵守剩余额度与既定范围，范围外汇总一次审批。

用户“只做审批”授权助手代办制作步骤，不等于无限扣费、自动购买积分、注册服务、接受新商业条款或发布。已批准的预算和操作范围跨步骤有效；不要把每次点击重新变成审批点。初稿、视觉与预算尚未齐备时，先完成可独立准备的部分，再提出具体审批。

## 可用执行通道与诚实边界

- 优先已有官方工具/API；没有已接通连接器时，可用已授权浏览器操作即梦实际页面。只使用已看到的控件与工具支持的上传/下载方法，不猜隐藏接口或宣称已接通不存在的API。
- 逐一验证当前模式、30秒选项、素材上限、报价、下载及任务状态；首页可访问仅证明浏览器入口可达，不证明四场生成链已跑通。不能把产品宣传等同当前账号权限。
- 平台不支持当前设置时先整理具体可行选项；保留用户4×30秒目标，不默默改成4×15秒、5秒试片或一条120秒。
- 助手在当前任务运行期间管理队列；没有另行配置调度或持续服务时，不承诺退出后仍自动执行。验证码、重新登录等只能用户处理的环节，说明具体原因并保留进度；不要把可代办的逐场上传推回用户。

## 批次与状态记录

每集保存本地任务清单：集名/版本、四场起止、画幅、素材路径与版本、角色/声音归属、提示词、内容批准范围、预算批准记录、已用/预留积分、场次任务ID、提交时间、状态、下载路径、文件校验值、审片结论与整片路径。凭据不写清单，私有资料不上传GitHub。

场次状态：待内容确认 → 待素材 → 待预算批准 → 可提交 → 提交中 → 已提交/生成中 → 可下载 → 已下载 → 待审片 → 可合成；失败和提交状态不明单独记录，不能直接当成未提交重试。

- 每场只保留一个当前有效版本，旧版本不删；改动哪场就更新哪场及受影响的相邻衔接。
- 点击生成前记录本次场次/版本与预计消耗；点击后立即记录页面任务ID或可识别记录。超时/断线先查任务历史、积分及状态，查明是否已提交后再决定，不盲目重发。
- 总预算包含已消费、已提交未结算及本次预计额；不因任务尚在排队忽略已承诺额度。仅在总额与重试次数都允许时追加。
- 审批绑定明确版本与范围。只修改技术格式且不改变批准内容可继续；身份、主要造型、核心剧情或费用超出范围须集中重新审批。

## 四场连续性与制作顺序

- 整集先看完整起落：第一场建立目标和钩子，第二场发展因果，第三场推动反转/选择，第四场兑现与收束；具体剧情服从用户已认可稿，不把每场硬写成独立误会。
- 每场内部按用户当前精细标准安排中近景、有效场景与动作B-roll、具体光源和声音；30秒场的台词默认25秒前结束、最后1.5秒构图焦点稳定，但不强迫表演归零。
- 建立跨场状态表：人物衣发、位置朝向、手中物品、桌面总数及归属、发生过的事、角色已知信息、光线与声源、上场结束/下场开始。不会以站位合成图作为默认前置条件。
- 无依赖场次可以在预算和页面并发能力范围内排队；依赖上一场实际成片状态的场次先审前场再提交。用户一次批准一批，不等于技术上盲目同时提交。
- 合成保留原声、不新增BGM；当前模式按明确授权在后期添加校对字幕，不用变速、循环、自动补帧或删剧情硬凑120秒。时长或衔接不合格先报告具体段落。

## 合成与完成判据

本仓库的 `scripts/assemble_episode.py` 是本地合成辅助，不会登录、上传或提交生成。输入四个已审查版本及校验值，先核对时长和顺序，再统一画布/帧率并拼接，保留原声；无音轨片段仅补静音以维持时轴。不覆盖已有输出，不拉伸人物。用户无需自己运行命令，助手执行。

完成状态必须分别说明：工作流规则已保存、浏览器入口已核实、上传/提交/下载实测范围、四段实片是否已审、整片是否已生成与用户是否批准。合成工具测试通过不等于实际即梦生成已跑通；演示素材不得出现在正式成片清单。
