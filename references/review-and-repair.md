# 成片复盘、审核诊断与修复

执行[规则裁决](rule-precedence.md)。先确认用户授权检查；仅收到视频或讨论失败原因，不自动授权编辑、重新生成或消耗积分。以下时长和工具路线是修复建议，实际入口与能力以用户当前平台为准。

## 先看真实成片

用户要求查看或分析视频且允许工具时：

1. 确认文件、时长、分辨率、帧率和音轨。
2. 每 2–3 秒抽帧生成接触表；再抽取问题区间的逐秒帧。
3. 检测切镜时间，计算空镜、人物镜、道具镜各占多少秒。
4. 同时检查声音、字幕泄漏、口型和环境声；不要只看静帧。
5. 把问题归入：参考图、提示词、时间预算、模型执行、后期五类。
6. 连续短片额外抽取结尾约 2.5 秒的 0.25 秒间隔帧，记录对白结束点、闭口点、眨眼点和字幕消失点；用最稳定帧续拍，不机械取最后一帧。

## 快速诊断矩阵

座位、道具复制及说前表演按[稳定协议0.13](../projects/bingbing/production-protocol.md#013-座位道具总数与直接开口2026-09-23用户确认)审计。只写过“面对面/每人一份/不叹气”不等于执行成功：核对相对桌边和固定场景锚点、主桌总数与每镜实际可见数量、参考物件是否被文字重复添加，以及是否仍在逐镜强制先笑再行动。未找到视频时只能报告用户反馈和文本风险，不能标注伪造的成片时间点；不因诊断擅自生成或重做素材。

| 症状 | 常见根因 | 优先修复 |
|---|---|---|
| 场景太旧 | 参考图材质/色偏 + “旧、胶片”重复强化 | 提出原图编辑建议，获同意后调整；保留现实维护状态 |
| 开场太慢 | 纯空镜占 3–4 秒 | 1—2秒有地点锚点的场景建立，或人物与环境同框；不强制首帧有人 |
| 世界太空 | 空场景图 + “禁止多余人物” | 恢复背景生态，禁止的只是额外剧情角色 |
| 人物换脸 | 多张身份卡竞争、角度覆盖不足 | 单一四视图卡，关键拍重复绑定 |
| 道具被替换 | 入画来源不清、相似白色物件竞争 | 独立道具卡 + 来源动作 + 替换禁令 |
| 出现字幕 | 台词触发默认字幕 | 台词拍和全局均写“只生成人声，不显示文字” |
| 首尾帧接不上 | 初始构图与已接受结束状态不一致 | 用户选首尾帧模式时匹配硬首帧；全能参考按已知结束状态衔接，不自行改模式或加图 |
| 人物左右没变但座位漂移 | 只锁人物画面左右，未锁课桌与空间锚点；空教室图重新解释布局 | 以真实尾帧锁桌面、窗户、柜墙和后排参照；后续用近景并撤掉冲突场景卡 |
| 桌面白线变宽、转斜或消失 | 把表面标记当成桌子附属细节；通用桌图没有该标记 | 将“桌面+白线”建成状态卡，记录宽度、走向和端点；每个可见镜头逐拍复述 |
| 走路占时太长 | 把功能性位移完整拍完 | 必要位移约2—3秒，纯功能位移累计通常≤4秒，跨空间用匹配剪辑；有关系变化的行走不是纯功能位移 |
| 道具像自行移动 | 缺少可见接触或运动路径被切断 | 同镜头拍清接触、启动、路径、停止 |
| 出现两份相似道具 | 手部镜头同时保留主道具与工具 | 只保留一个核心道具，其余移到画外 |
| 没有可用尾帧 | 台词压到最后、末帧眨眼或张嘴 | 本剧全部台词25秒前结束，最后5秒无台词，最后1.5秒闭口、构图和焦点稳定 |
| 人物说话很慢 | 台词被拉满整个时间窗、逐字停顿 | 设定 3.5–4.5 字/秒，2–3 秒说完短句，余时反应 |
| 所有人都用同一种慢语速 | 把“自然、克制”误解为全段慢读，没有按情绪分配语速曲线 | 平静3.5—4.5、活泼4.5—5.5、短促反击5.5—6.5字/秒；只有犹豫和受伤才主动放慢 |
| 说话像AI念稿 | 缺少事件动机，或模板强迫逐句执行同一套动作 | 写动机、自然语气与必要反应；不强制说前动作、吸气或说后呼气 |
| 听者像暂停画面 | 只要求闭口，未设计听觉反应 | 让听者在关键词附近出现一次眼神、眉峰、呼吸或坐姿变化，但不同时开口 |
| 全程抿嘴微笑 | 全局重复同一表情标签 | 删除常驻微笑，写起始—变化—回落的表情弧 |
| 人物像等指令 | 非说话人物只写“闭口不动” | 加一次眨眼、视线转移、呼吸或手部小动作 |
| 全片拖拖拉拉 | 机械使用5秒等长分块 | 混排1—2秒插入、2—3秒叙事、3—5秒表演，压缩纯功能动作 |
| 原定剧本在集内做不完 | 先切固定格、功能动作占时过多 | 先列已确认节点再分秒，核对累计进度和剩余剧情，不为凑信息数量编剧情 |
| 为做完剧情临时加段加时 | 前段没有时长预算，直到后段才发现核心节点被挤掉 | 开拍前把全剧本映射到预计生成次数；每段完成后更新覆盖表，禁止默默删剧情 |
| 对话没有代入感 | 多句对白长期停留在同一双人中远景 | 说话人近景、听者反应近景、关系落点双人镜头；重要词处轻推近 |
| 审核不通过 | 素材或语义组合冲突 | 一次改一个变量并隔离素材，不盲猜单一触发词 |

## 清晰度与AI感诊断（2026-09-19）

- 用户描述“脸糊、像AI、每句叹气”先作为用户反馈记录；没看真实视频不能声称定位到具体秒或唯一原因。
- 获准后比较原始生成片与平台展示片，核对真实分辨率、人物占画面比例、参考身份、焦点/景深、脸部受光、运动拖影和后期压缩。中远景并非天然不能清晰，不把焦段词或高清形容词当作修复保证。
- 每句开头先吸气/叹气：先查模板是否逐句要求呼吸与回落，取消无动机的重复表演，不把所有人改成停止呼吸的定格。
- 表白后男主反应平淡：对照用户情绪节点，检查声音、表情和动作是否一致；稳重不能作为取消开心激动的理由。
- 先修最小问题区间与冲突指令，保留已可用成片；不自动重跑、不承诺一次生成通过。不引入用户已决定不启用的外部工作流。

## 审核修复原则

- 明确“审核拦截”和“生成失败”的区别；记录是否扣积分及页面提示。
- 不把概率判断包装成官方规则。
- 只排查相互矛盾的身份、年龄或场景标签；不擅自删除或改写已确认18岁、高三等设定，保留摄影、光线、表演、声音和生态细节。
- 不反复原样再次生成。先重新编辑，最小变量测试。
- 隔离顺序：场景+道具 → 单角色 → 双角色 → 台词/音频。由结果定位素材还是文本。

## 选择修复路径

- 全局环境、参考图、人物数量或整体节奏错误：先给修改建议，按授权调整素材或提示词，再由用户决定生成。
- 中间一处物件、字幕或动作错误：按当前平台编辑限制裁取问题区间，一次只改一处。
- 结尾错误：保留原片，选真实衔接点，按当前延长入口限制准备母片副本；不把上游8–15秒建议当固定上限。
- 中间整段表演错误：使用分段重拍，不整条重跑。

## 把反馈变成下一次固定规则

每次复盘输出：观察到的事实与时间点、根因及置信度、最小修改、可复用的新检查项。只有能跨项目复用的经验才进入 skill；单次审美偏好保留在项目提示词中。

## 连续短片提交门禁

在用户消耗积分前逐项通过：

1. **衔接模式**：沿用用户选定的全能参考/首尾帧/延长模式；有授权且素材可用才检查真实尾帧，否则依据已确认结束状态，不声称已看成片。
2. **状态账本**：人物左右、轴线、姿态、道具数量/位置、光线和背景人数无冲突。
3. **时间预算**：开场不重置；纯功能位移累计通常≤4秒；已确认核心互动获得主要时长。
4. **物理因果**：道具的来源、接触、启动、路径、停止和结尾位置均可见。
5. **单一道具**：手部近景不存在相似工具竞争或无意复制。
6. **人物排他特征**：痣、发型、饰品等只属于指定人物，不串脸。
7. **声音文字**：音色挂载与说话人一一对应；字幕/音乐规则在全局和台词拍一致，并提醒检查页面开关。
8. **稳定尾帧**：本剧全部台词25秒前结束，最后5秒无台词，最后1.5秒闭口且机位、构图和焦点稳定。
9. **积分保护**：接受的历史错误用遮蔽和连续性绕开；没有影响叙事时不建议整段重跑。
10. **对白与表情**：短句不占满 5 秒；同一种笑不连续复制；非说话人物有自然反应而非定格。
11. **摄影与节奏**：逐镜有焦段mm、景别、机位、运镜；混排短插入与核心表演，前中后各有有效场景镜头。
12. **对白覆盖**：重要台词是否给到对应说话人的单人近景；听者是否有反应近景；相似双人中景是否连续超过约6秒。
13. **画面不变量**：已出现的表面标记、桌面物件、背景锚点和光线方向是否写成可观察事实，并在实际可见的时间窗逐拍复述。
14. **真人台词表演**：是否有事件动机、适当语气和听者反应；是否误把所有情绪处理成慢读、叹气、统一微笑或逐句情绪回零。
15. **剧情覆盖**：本段是否完成已确认节点；功能动作是否过长；本集剩余时长是否足以覆盖已确认剧本；不为了满足固定信息数量编造事件。
16. **续段记忆**：段号及续写/替换/补拍范围正确，已用台词和角色已知信息没有重演；未确认草稿没有被当作成片事实。
17. **声音类型**：画内对白、消息画外音、内心独白和电话分开标注，可见嘴唇状态与音色一致；配角声音不借用女主，不虚构音色素材。
18. **参考可用性**：用户没保存或本段不用的图不列必传；角色、固定场景、家具、道具各有真实引用。左右手没有被手机、礼盒、钥匙扣和牵手重复占用。
