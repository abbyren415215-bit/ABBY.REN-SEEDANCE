# 成片复盘、审核诊断与修复

## 先看真实成片

用户给视频时：

1. 确认文件、时长、分辨率、帧率和音轨。
2. 每 2–3 秒抽帧生成接触表；再抽取问题区间的逐秒帧。
3. 检测切镜时间，计算空镜、人物镜、道具镜各占多少秒。
4. 同时检查声音、字幕泄漏、口型和环境声；不要只看静帧。
5. 把问题归入：参考图、提示词、时间预算、模型执行、后期五类。

## 快速诊断矩阵

| 症状 | 常见根因 | 优先修复 |
|---|---|---|
| 场景太旧 | 参考图材质/色偏 + “旧、胶片”重复强化 | 编辑原场景图，再精确限定维护与色偏 |
| 开场太慢 | 纯空镜占 3–4 秒 | 主角第一帧可见，环境建立并入首拍 |
| 世界太空 | 空场景图 + “禁止多余人物” | 恢复背景生态，禁止的只是额外剧情角色 |
| 人物换脸 | 多张身份卡竞争、角度覆盖不足 | 单一四视图卡，关键拍重复绑定 |
| 道具被替换 | 入画来源不清、相似白色物件竞争 | 独立道具卡 + 来源动作 + 替换禁令 |
| 出现字幕 | 台词触发默认字幕 | 台词拍和全局均写“只生成人声，不显示文字” |
| 审核不通过 | 素材或语义组合冲突 | 一次改一个变量并隔离素材，不盲猜单一触发词 |

## 审核修复原则

- 明确“审核拦截”和“生成失败”的区别；记录是否扣积分及页面提示。
- 不把概率判断包装成官方规则。
- 只删可能冲突的身份、年龄或场景标签；保留摄影、光线、表演、声音和生态细节。
- 不反复原样再次生成。先重新编辑，最小变量测试。
- 隔离顺序：场景+道具 → 单角色 → 双角色 → 台词/音频。由结果定位素材还是文本。

## 选择修复路径

- 全局环境、参考图、人物数量或整体节奏错误：更新参考图和完整提示词后，以低分辨率重跑。
- 中间一处物件、字幕或动作错误：裁到 ≤20 秒，使用智能编辑，一次只改一处。
- 结尾错误：裁掉旧结尾，以 8–15 秒母片向后延长。
- 中间整段表演错误：使用分段重拍，不整条重跑。

## 把反馈变成下一次固定规则

每次复盘输出：观察到的事实与时间点、根因及置信度、最小修改、可复用的新检查项。只有能跨项目复用的经验才进入 skill；单次审美偏好保留在项目提示词中。
