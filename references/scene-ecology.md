# 场景生态：让故事只属于主角，让世界仍然活着

## 核心分层

### 剧情角色

只包括用户指定的主角与必要配角。他们拥有姓名、台词、情绪弧线、特写与剧情动作。

### 背景生态

包括背景群演、交通、营业设施、服务人员、环境声音和持续运动。它们不参与剧情，但证明地点正在正常运转。

固定句式：

```text
除[主角名单]外，不增加参与剧情的角色；场景中保留符合现实密度的背景生态。
背景人物只进行低幅度日常活动，不与主角互动、不看镜头、不抢占前景；
禁止重复脸、克隆人物、动作整齐同步、人数或位置在相邻镜头中突然变化。
```

## 五层生态检查

1. **人口层**：谁应该在场，数量或密度是多少，分布在哪里。
2. **流动层**：人、车、门、电梯、窗帘、树影朝哪个方向运动。
3. **运营层**：店铺是否营业、灯是否点亮、柜台是否工作、交通是否通行。
4. **物件层**：桌椅占用率、杯盘、书本、购物袋、灯牌等是否符合使用状态。
5. **声音层**：人声底噪、翻页、车流、门铃、广播、掌声等如何随景别变化。

## 常见场景预设

### 教室

- 中广景保留约 12–20 名背景同学，分布于前后排，不坐满每个座位。
- 动作错开：写字、翻书、整理纸张、短暂低声交流、有人从过道经过。
- 主角近景中，背景同学仍以柔和虚焦轮廓存在，不能突然清空。
- 声音：翻页、笔尖、椅脚、低声交谈、窗外鸟鸣或操场远声。

### 街道

- 定义时段与街区等级后再决定行人/车流密度。
- 车辆沿合法车道同向流动；停靠车与行驶车分开；红灯时流量变化合理。
- 店铺有开门、灯光、橱窗或顾客进出状态；不要生成整条关闭的“影视城街道”。
- 声音：近处轮胎与脚步、远处喇叭、信号提示音，随镜头距离变化。

### 咖啡店/餐厅

- 保留少量顾客、店员、邻桌餐具活动和门口进出。
- 群演不集体举杯、不统一转头，不走入主角焦平面。
- 明确营业状态、桌面使用率、收银台和制作区是否工作。

### 演唱会

- 观众数量必须与场地规模匹配，前景、中景、远景形成密度层次。
- 灯牌、挥手、手机屏幕与身体起伏异步，不复制同一动作。
- 主角仍是唯一剧情主体；观众不突然冲上台或直视镜头。

### 车站/机场

- 保留候车、排队、上下车、行李拖行和信息屏变化。
- 人流方向符合入口、出口、站台或登机口结构。
- 广播、刹车、开门提示音应与事件同步。

## 镜头与连续性

- 中广景明确人口密度；中近景保留背景活动；特写用虚化轮廓和声音维持世界存在。
- 跨镜头记录背景人数范围、主要流向、店铺状态、光线和天气。
- 场景真正空旷时写明原因：放学后、闭店、封路、深夜或活动结束。
- 不为真实感堆满所有元素；背景只需足够证明场景正常运行。
