# 素材画布确认、逐段授权与成片验收

画布的最新定义见[人物与剧情关系画布](story-relationship-canvas.md)：核心是人物、情节、场景和物品之间的联系，不只放图片，也不默认使用即梦画布。图片按用户指定工作流准备，视频生成授权单独记录。

2026-09-27用户明确选择更细的积分控制：先剧本、再素材画布、逐段生成并检查，全部片段通过后才剪成整集。本模式优先于旧的集中批次审批；不撤销助手代办上传、填写、查询、下载和剪辑的职责。

## 执行顺序

1. **剧本先行**：交付完整故事与台词，标明草稿；未选定剧本不提交视频。用户说“先不要生成”立即停止新的提交，不能把过去的“跑吧”当持续付费授权。
2. **素材画布**：把本集使用的全部人物、造型、场景、家具和关键物品按类别放在同一审阅画布，显示实际图片、版本、用途与数量。已有参考、文字方案、待制作图片、已生成未确认图片、已确认可用图片分开标明。占位框或方案文字不是素材已完成；没有图片时不能声称视觉已通过。画布只是审阅方式，不生成多人站位或共同持物合成图作为额外前置条件。
3. **图片授权与验收分开**：新生或修改人物、场景、物品图片前取得对应工具、范围及费用授权。生成后先放回画布交用户确认；批准生图不等于批准将其用于视频。用户指定人物制作平台时沿用；句子未说完或平台未知时先准备文字方案，不擅自选收费入口。
4. **每段提交前**：标明本段编号、30秒等实际时长、用户指定画幅与分辨率、已确认素材版本、预计积分及本次条数。只在用户明确同意生成本段后提交一条；不得因余额足够、整集已估价或前段正在排队就连交后段。
5. **每段提交后**：记录任务ID、实际扣费/待结算与下载文件；助手先检查，再交可播放视频给用户。未经用户验收通过不继续下一段；单纯“这段可以”不扩大成未说明范围的付费授权，用户“通过，继续下一段”可同时构成下一段授权。
6. **失败与重做**：先说明具体问题、可用内容及最小修改方案。重做、替换、补镜需用户明确批准该次消耗；不把预留预算或页面重试按钮理解为自动重跑许可。状态不明先查询原任务，避免重复扣费。
7. **整集交付**：所有片段由用户通过后，剪辑批准的版本，按实际对白转写校对并加入字幕，交付完整一集。生成无BGM无字幕，最终无BGM、按本模式加后期字幕；原片保留，不自动发布。

## 成本记录与每次汇报

本地流水按操作保存：素材/段号、版本、任务ID、工具与设置、提交前报价、实际扣费、待结算积分、退款、用户授权原文或明确范围、当前结果。图片、视频、失败及重试均计入本集，不只算最终采用的片段。

每次生成完成主动报告：本次操作与状态；本次实际消耗；本集图片累计、视频累计、总累计；如有则列待结算与已确认退款。没有实扣证据时写“页面报价/待确认”，不冒称精确实耗。仅积分数据不自动换算人民币或美元；无明确换算依据时不提供货币成本。

## 适用范围与状态

- 本模块规定审批粒度；画幅、分辨率、预算和素材平台取当前项目明确决定，不固化某一集的机器路径、报价、媒体或人物设定。
- 建议状态：待剧本确认 → 待图片制作授权 → 待素材画布确认 → 待本段生成授权 → 生成中 → 已下载待助手检查 → 待用户验收 → 本段通过 → 待下一段授权；全部通过后才进入剪辑。
- 图像/视频任务的预算批准字段和素材/片段验收字段独立，不以其中一项覆盖另一项。当前用户选择逐段模式时，旧批次预算与自动重试建议不作为有效授权。
