# 新旧规则裁决

本文件是执行规则。`upstream/jacob/` 是原作者的版本快照，保留原文不表示接受其中所有默认值或平台断言。优先级：用户当前明确决定 → 项目已确认状态与规则 → ABBY 统一入口及增强 → JACOB 原文。

| 冲突来源 | 本项目执行规则 |
|---|---|
| 原文每镜≥3秒；旧ABBY仅混排2/3/4/5秒 | 《冰冰和小乌龟》采用1—2秒短插入、2—3秒叙事和3—5秒表演混排，每镜负荷与时长相称 |
| 原文焦段要求埋在公式与检查表 | 将焦段、景别、机位、运镜前置为每镜头必写字段，包含环境插入镜头 |
| 原文提示词不写比例/时长 | 本剧标题和全局明确16:9横屏、30秒，并与页面设置一致 |
| 原文环境:人物固定5:3；旧ABBY主角首帧必须可见 | 本剧前5秒、中段、最后5秒各有有效场景镜头，通常场景合计4—7秒；不强制首帧有人，不强制5:3 |
| 原文每场必须接近/进场、跨时空用15—20秒桥段 | 已确认进场不重复；续段承接既定结束状态，短动作匹配切/声音桥按本段预算设计 |
| 原文第三个同轴特写必须“换轴” | 换覆盖角度和景别，不强制跨越180度轴线；屏幕左右变化必须有依据 |
| 旧ABBY最后一句27.5秒开始/留1秒尾帧 | 本剧全部台词25.0秒前完整结束，最后5秒无台词，最后1.5秒闭口且镜头/构图/焦点稳定 |
| 通用Seedance Director默认三个版本、配乐和运行脚本 | 本剧只给一个最终版本、禁止BGM；只要提示词不自动运行生成脚本。必要技能文本读取和长度核对按入口授权，明确禁止工具时不读取 |
| 原文优先独立场景单图并否定四宫格 | 保留用户已确认的四视图，明确同地点不同角度与排版排除，不要求重做素材 |
| 原文角色卡绑定后禁止任何外貌/服装文字 | 避免编造五官散文；保留用户明确要求的年龄、身高、发型、衣服、鞋、包和独有识别特征 |
| 旧协议“素材永远高于文字” | 素材在各自职责内锁定；用户最新明确修正（如183cm而非旧188cm）优先，不借错误旧图推翻事实 |
| 旧协议强制检查成片/硬首帧槽 | 仅在用户授权读取且素材可用时检查；全能参考不被自动改成首尾帧/延长模式，不额外索要未使用素材 |
| 上游改图、重绘、补素材建议 | 先遵守图片操作授权；没有同意不生成/修改图片，也不因流程模板凭空要求新图 |
| 旧脚本硬编码其他模型时长和模式 | 不套用于本剧30秒Seedance 2.5；用本项目检查，未经验证不声明平台硬上限 |
| 上游“保证过审”、固定失败概率/退款机制、医学式表情解释 | 留作作者历史判断，不当作当前官方事实或保证；本项目只用可观察表演和实际页面反馈 |
| 上游版权与来源 | 原文及署名保留；ABBY 修改在NOTICE与CHANGELOG中标识，不冒充原作者更新 |
| 旧模板逐句吸气、说后呼气、每拍恢复中性、至少三种表情 | 动作服从事件，不设呼吸仪式；情绪承接上一镜，开心可以持续，稳重不等于平淡 |
| 旧“反转信息25秒前全部交代” | 所有人声25秒前结束；无台词视觉揭示可在25—28.5秒，最后1.5秒稳定且不引入新信息 |
| 旧“对白均对口型”及“禁止第三人清晰对白” | 画内对白对口型；消息画外音/内心独白时人物闭口；指定妈妈等配角可说已确认台词，禁止额外背景对白 |
| 旧“环境镜头等于空镜”“已生成参考即必传” | 人物与环境关系镜头可以承担有效场景职责；只列本段使用且用户实际可用的素材 |
| 历史“不能突然告白”与“女主固定高丸子” | 日常/校园默认不覆盖本地剧本中用户最新确认的关系进度与当集造型 |
| 外部项目调研与星标讨论 | 调研不等于采用授权；其后用户明确批准的独立30秒参考库安装按standalone-30s.md执行，ABBY／JACOB仍是唯一工作流，不改变原剧集规则 |
| 新参考库的完整流程、默认审美与平台数字 | 只吸收当前镜头需要的导演、摄影、质感、空间和精简方法；不叠加十字段问卷、逐次确认、固定胶片/颗粒/柔焦、英文交付、固定字数或旧时长/素材上限 |
| 旧“只要提示词”一律禁止读取技能 | 最新用户授权自动选用合适技能；允许最少必要的已安装文本读取与长度核对，已读规则复用。明确“不用工具/不要读文件”仍优先，不自动扩大素材分析、生成或发布范围 |
| 短剧默认与独立AI弹唱冲突 | 唱歌按lip-sync-singing.md，一句歌词一段，沿用指定音频与伴奏；不套禁歌、30秒/25秒截止、强制尾段睁眼或场景插镜。剧集本身的规则不变 |

全局“保持一致”不能代替可观察状态，但不为重复状态塞满提示词。内部推理、剧情覆盖表、表演卡和门禁可在内部完成；用户只要最终文字时不再展开教学。

对话最新确认不等于模型草稿：用户明确锁定的剧情和台词才能进入项目状态；助手生成的镜头版本仍是待确认草稿，不能反过来覆盖用户。
