# JJTV 制作规矩（公开版）

Abby 在 JJTV 项目里用 Claude Code 做 AI 短剧时，一路定下来的制作规矩，按系列分开存放。

- [00 全局制作规矩](00-全局制作规矩.md)：所有系列都要守的规矩，包括开工流程、花钱先报价、剧本铁律、BGM、封面、发布。
- [01《ABBY的加州日记》](01-ABBY的加州日记.md)：家庭搞笑剧，写实，横屏，Seedance。
- [02《ABBY的美国故事》](02-ABBY的美国故事.md)：第一人称个人经历，冷青绿色调，写实克制，Seedance。
- [03 兄妹动画系列](03-兄妹动画系列.md)：皮克斯风格 3D 动画，竖屏，H3。
- [04《Abby and My Pets》](04-Abby-and-My-Pets.md)：真人加拟真动物，全英文，竖屏，H3。
- [05《ABBY的人生副本》](05-ABBY的人生副本.md)：一集体验一个国家的一个行业，闯关主题，Seedance。

各系列的风格互不混用。规范里如有新旧冲突，以较新日期的那条为准。

公开版已去掉真人姓名、电脑路径、账号和任务号，人名都换成了角色称呼。不含图片、音色、成片和密钥。
