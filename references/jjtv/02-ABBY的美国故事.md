## 二、固定做法

1. 第一秒就进场景、上问题；每 20–30 秒有一次新的碰壁 / 新事，节奏点密。
2. **标题直白、能被搜到**：「我的 XX 经历……」+ 话题 #XX #AIGC #美国生活，不玩梗。
3. **真实感**：选大家都经历过的事；评论区里观众的真实经历可以当下一集素材。
4. 实用信息放进**置顶评论 / 文案**，片子本身照第 1 集安静收住；家暴这类必须给求助电话的题材例外，放片尾 3 秒字卡（先查官方原文）。
5. **不用敏感字**：不写「遣返」「身份」「绿卡」「非法」这类字；暴力不实拍（例：抬手 → 黑屏 → 声音 → 结果）。
6. **不针对群体**：坏人只是「这一个人」，不拍成「美国人都这样」。
7. **置顶评论**：问观众自己的同类经历。
8. 不出现品牌；发布时标注 AI 生成。
9. **剧本铁律（所有系列通用）在本系列的落实**：抓住观众、第一秒上问题、悬念和节奏点密、不拖沓、剧情紧凑都照做；**本系列不抖包袱，但要反转、反差、曲折、虐（11-01 起）**——「笑点」换成「面部表情细节戏」。给 Abby 看剧本时附一行「反转 N 个 / 反差 N 处 / 第一秒是什么 / 结尾那句感受」。

- **BGM 跟着对白自动变音量（写死，所有系列）**（Abby 2026-10-24：「美签那一条……背景BGM配的很好，并且人物在说话的时候BGM会自动根据人物说话变化音量，这个我们也要借鉴」）：BGM 一律用工具包 `<本地>/jjtv-kit/mix_bgm.py` 混（自带侧链压缩：人一开口音乐自动压低，没人说话时音乐回到正常音量），不手动一刀切音量、不自己另写混音脚本。没人说话的段落让音乐撑起情绪，有对白时对白清楚在前。混完先自己听一遍对白是否清楚、空档里音乐是否明显，再给 Abby。

- **标题直白、能搜到；结尾让人留言、追下一集（写死，所有系列）**（Abby 2026-10-24 定）：
  - 标题用大家会搜的词（「美国看病」「小孩学英语」……），直白说清这集讲什么，不玩梗。
  - 结尾抛一个两边都有道理、观众忍不住想说的问题；发布时配一条同样问题的置顶评论。
  - 片尾用一句话或一个画面预告下一集；同系列放进同一个合集 / 播放列表。（**本系列 EP03 Abby：「片尾不要预告」，片尾画面慢淡到黑；是只这集还是以后都不要，待确认**）

- **斯坦尼康跟拍，能用上就用上（写死，所有系列）**（Abby 2026-10-24：「能用上的时候就用上」）：开场跟着人物 / 宠物进新地点、房间之间的转场、追逐戏，优先用斯坦尼康式平滑跟拍（提示词写 Steadicam follow shot, smooth gliding camera following …；Seedance 线在白模里把机位沿路线平滑移动）。一段只走一条简单路线；对白戏仍以稳定正反打为主，全片不要处处在动。H3 段只有 10–15 秒，跟拍要短（跟几步、跟到门口）。
