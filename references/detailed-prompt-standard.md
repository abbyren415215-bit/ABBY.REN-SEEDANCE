# 精细提示词标准：从已认可的《发如雪》提炼

2026-09-26用户明确裁决：以用户重新贴出的《发如雪》月光庭院扇舞完整提示词为写作质量标杆。用户认可的是细节充分、动作明确且此次生成有效；此前芭蕾结果不满意，不作为成功示例。半自动制作分工继续有效，流程准备完成不等于成片被认可。本模块记录可复用写法，不把一次成功宣称为平台保证；案例原文与媒体在本地留档。

适用于有提示词输入的完整视频、动作参考舞蹈及补镜；由唯一入口自动调用。逐句对口型保留其独立长度与固定镜头约束，没有文字栏的动作模仿入口不强塞本模板。简短创意讨论不必展开成长分镜。

## 1. 保存细节密度，不退回概括稿

用户要最终提示词时，直接交付可执行完整版，不能把本标准压成“参考动作跳舞、优雅转身、穿插手部特写”。详细程度以关键变化能被读者连续想象、上一动作能接入下一动作为准，不以堆满形容词或固定字数为准。

- **镜头层**划分观看职责；**镜内节拍层**写动作过程。标杆中的密集动作常以约0.4—1.2秒说明一段变化，这是根据动作设计的密度示例，不是每半秒必须切镜或每支片固定14镜。
- 不能跨过几秒内发生的收扇、抬臂、转背、转回，只剩一句“她旋转”。简单延续或稳定末势允许用一段描述，不为了填时间新增表演。
- “一镜一个核心动作”指一个连续动作句，可以含重心、腰肩、肘腕、道具和视线的先后协同；不拆成逐项摆姿、每步停住，不与自然表演协议冲突。
- 时间精度来源于实际动作观察；小数秒不是证据。没看见的过程不能为了写得细而编造成原片事实。
- 未遇到实际输入限制时，不主动删成稀疏提纲。确需压缩时先删同义赞美和重复背景；保留动作路径、持物、衔接和关键声音约束。不能以“省token”替代用户要的细致交付，也不因此反复搜索外部资料。

## 2. 四层文本结构

1. **素材与职责**：逐份绑定实际素材；动作视频管顺序、速度、朝向与道具开合，人物图管身份及造型，场景图管空间与光源。多视图是同一人。排除已经确认的录屏残影、跳帧等，不默认每条视频都有这些问题。
2. **全局执行条件**：人物和道具数量、持物归属、主要景别、关键动作完整性、身体协同、服装遮蔽、统一光源与声音。用当次确认的事实，不照抄标杆服装或持扇手。
3. **逐镜与镜内节拍**：每镜完整摄影字段；内部按实际变化分配短时间段，写动作而非抽象感受。
4. **末尾总约束**：复核跨镜连续、真实结尾、禁止重复动作与声音/字幕要求。关键约束全局定义、易错镜头局部落实、末尾收束；避免每句话堆一长串禁令。

## 3. 一段动作写到什么程度

按画面可见性选择以下信息，组成自然连贯的句子，不机械逐项罗列肌肉：

`谁/哪只手或腿 → 起始位置与状态 → 经过哪里、朝什么方向 → 发力或带动关系与先后 → 接触/遮挡/距离 → 头眼回应 → 可见结束状态`。

| 维度 | 应明确的内容 | 容易丢失的细节 |
|---|---|---|
| 身体方向 | 人物自身左右、前侧/侧面/背面、支撑侧 | 屏幕左右变化不等于换手；转身不是瞬移 |
| 运动路径 | 胸前到脸侧、侧下到斜上、越过头顶再回落 | “挥扇”不能替代起点、弧线、扇面朝向和终点 |
| 先后与重量 | 重心先移动，腰背带肩肘，腕部完成道具转向 | 双臂不机械同步；屈腿、回落要接续支撑 |
| 手与道具 | 握点、轴心、展开程度、翻转方向、另一手距离 | 收扇不能靠消失；另一手呼应不等于接走 |
| 视线与面部 | 先看手势再从扇缘露出、随肩线自然回望 | 不无故加微笑、眨眼、甩头或聊天口型 |
| 次级运动 | 主体先动，衣摆/耳饰/流苏稍后跟随和落定 | 不各自乱摆；刺绣不游动；服装遮蔽不突变 |
| 结束与衔接 | 当前身体朝向、手与扇的位置、下一动作准备 | “保持一致”不够；结束必须是画框能看见的状态 |

描述应以正向动作带动局部防错。例如“扇骨围绕同一轴心依次聚拢，握点保持不变”，再补“不用消失替代收扇”。负面约束对应眼前的生成风险，不添加与本镜无关的长名单。

## 4. 标杆级细节示例（写法示范，不预设新素材动作）

**手部开扇近景**：85mm，胸前双手与完整扇面近景，胸口高度，固定。持扇手拇指与其余手指围绕扇轴发力，扇骨从收拢状态顺次展开；手腕随后旋转，使扇面由朝向镜头转为斜向，再由前臂带到脸侧。另一只手沿扇缘附近经过，保持可见距离，不接走道具。握点留在原轴心附近，流苏晚于转腕摆动。侧窗光掠过扇骨，衣领留作空间锚点；只有轻微开扇声和衣料声。结束在展开扇面靠近脸侧的位置，下一镜从此接入。

**连续转身的镜内节拍**：先写上举手臂沿弧线回收、前臂经过胸前；再写脚下换重心带动腰肩转向背面；最后写身体继续转回前侧，闭扇横向经过胸口到下颌附近。三段时间依参考填写，属于一个连续转身镜头。头部随肩线转动，另一手呼应但不抢扇。不要用“优雅转一圈”替代，也不要凭空规定参考里没有的旋转圈数。

**衣料细节插镜**：持扇手沿身前降至胯侧，肘部自然弯曲；腰身随重心侧移，腰侧斜褶短暂形成后舒展，刺绣留在原衣料位置。扇面由近身转为朝外倾斜，扇穗稍晚落下。该镜看清同一次动作的结果，不另加抚衣或重新摆扇。

这些例子说明所需信息密度；实际人物、道具、衣服、镜头时长、焦段和动作仍依据本次任务。

## 5. B-roll 的三个连接点

每段插镜必须能回答：**从哪一动作状态切入 → 特写揭示什么变化 → 以什么状态接回主镜**。

- 标杆在开扇、扇面下降、落脚交接、收扇转腕处靠近；展示同一次动作，不为了镜头重新开一次扇或重走一步。
- 面部近景承接原有视线和回望；允许扇缘短暂遮脸再露出眼睛，不强求时时完整露脸，也不为“好看”另加无因表情。
- 脚步看接触和重心；参考未显示时明确是最小合理补拍，不能冒充原舞细节。鞋型遵从人物图，细跟接地不改为芭蕾足尖动作。
- 环境细节须与人物当时行为同一时空，如石面落脚与同方向影子。场景本身不必远景，也不因通用B-roll配额加入无关空镜。
- 关键转身、后屈腿、抬腿定势保留连续观看；切点避开会丢失支撑关系或动作峰值的位置。
- 返回中景时，时间继续向前，身体朝向、动作相位、持物手、扇面开合与速度均承接；不能通过重复片段填满时长。

## 6. 摄影、光源与声源都要落到本镜

逐镜包含：`起止时间｜焦段mm｜景别与可见边界｜机位高度/方位｜主运镜或固定｜动作微节拍｜焦点/空间锚点｜光源及受光变化｜具体声源｜可见结束状态`。

- 中景先交代画框到哪里、手和道具需要多少空间；关键动作可适度放宽，但不为露鞋底自动退成人物很小的远景。局部镜头不要求同时证明全身比例。
- 机位跟随与演员转身分开写。一镜一个主运镜，指定跟随对象和范围；固定镜头中的人物仍可呼吸、转动和自然衔接。
- 光写“来源→照到哪里→转身后的变化”。例如同一侧窗光在转背时离开正脸、转回时重新照亮脸，月光维持发髻轮廓。不能切镜就换光源左右，也不能靠“电影感”替代受光描述。
- 声音写具体事件与强度：开扇、合扇、衣料、实际落脚、合理环境底声。没有接触不凭空配落脚声，不给每个转腕加夸张呼啸。
- 沿用用户当前无BGM、无歌曲/哼唱/鼓点/音乐性转场、无字幕的要求；纯舞蹈无对白和旁白。将来明确授权音乐或有对白剧情时按当前任务处理，不误禁唱歌模式。

## 7. 交付前验收与复用范围

检查：完整时间轴是否覆盖目标；忙碌数秒是否被空泛一句带过；关键舞句是否切碎；每次插镜能否接回；道具是否有唯一归属与真实运动；画外事实是否标明补足；每镜摄影、光源、声源、结束状态是否齐全；原舞末势是否被擅改。

用户确认的原文优先于助手以前的概括稿；以后新作品按这一级可执行细节展开，不要求用户反复提醒。只复用写作方法与已确认偏好，不把30秒、3:4、特定月光庭院、香槟旗袍、粉扇、左手握持或具体秒点规定成所有作品的固定内容。

结果记录区分“素材已备齐”“已经生成”“用户认可”“实际检查通过”。用户不满意的案例不作推荐范例，保留历史材料，不删除原件；本次认可不承诺将来一次成功。只要提示词就给一个完整版，不额外输出本验收表。

## 2026-09-27：剧情合理性与生成前成本保护

用户要求加强剧情流畅性和合理性，优先在提示词中排除错误以减少重跑。适用于叙事短片，不强套唱歌、舞蹈或纯展示。

- 每个交易与交接，先核对约定总额、已付款、未付款、物件去向和角色离场目的；镜头中的关键数值与物件数量对应，不能仅写“交钱”“离开”。
- 观众必须能从画面或台词理解关键原因。仅在提示词后台写“等待寄出”等解释，不能视作片内已交代。功能动作缩短，关键理解与反应保留。
- 若用户保留有偏差的前片，记录为“保留且有已知问题”，不能改成全面验收通过；续段按真实末态写，不按未实现的原稿写。新增前史只能作为待确认的剧情提议，不冒充已拍事实，不用假字幕遮掩原对白。
- 正向写清数额、来源、接触、手部职责与终点；细节用于消除歧义，不靠重复禁令或更长文字保证一次成功。降低金额、计数、复杂手部动作同时出现的负担。
- 默认直接开口、不逐句叹气；用户为具体情绪指定叹气时，仅在指定节点允许一次，写明触发、时段和结束，不将局部授权扩为全片模板。强情绪反差优先同镜连续呈现，并给触发留出可感知时间。
- 改动段尾必须同步检查下段开头、持物、通话是否已接通、容器开合等状态；失效旧稿标记不可提交。具体金额、对白、影片与项目进度留本地。
